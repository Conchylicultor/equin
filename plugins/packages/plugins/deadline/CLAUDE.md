# deadline

`withDeadline(work, budgetMs, onTimeout)` awaits `work` for at most `budgetMs`.
On expiry it rejects with the caller's `onTimeout()` error; when `work` rejects
first, its own error wins. The timer is one-shot and always cleared, so a fast
success leaves nothing pending.

It **bounds the wait, never the work**: nothing is cancelled. The caller keeps
its handle on `work` and decides what a still-running promise means (keep a
memo, report it, leave it running). Use it for an await with no timeout option
of its own — a module import, a run a bug may never settle.

Used by `infra/safe-fetch/browser-fetch` (the Playwright import) and
`conversations/runtime-sdk` (the event consumer's catch-up watchdog).
