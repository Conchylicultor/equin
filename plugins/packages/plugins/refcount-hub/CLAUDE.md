# refcount-hub

`createRefcountHub(open)` → `{ acquire(key, listener) → { ready, release }, has, keys }`:
one underlying subscription per key, however many holders want it. The first
acquire of a key calls `open(key, emit)`; every event `emit` delivers fans out to
each holder; the last release runs the stop `open` returned.

Reach for it whenever a resource "watches X while someone reads it" and several
readers can want the same X — a file watch, a source's change feed, a per-checkout
computation. Do not hand-roll the `Map<key, { listeners, stop }>` again.

- `open` may be **sync** (returns the stop) or **async** (returns a promise of it).
  An async open is shared while in flight: a second acquire joins it. A failed
  open rejects every holder's `ready`, and is forgotten, so the next acquire
  retries. A sync open that throws throws from `acquire`.
- A last release that lands while the open is still in flight stops the
  subscription as soon as it opens.
- A release is idempotent; the same listener acquired twice is two holds.
- A throwing listener does not starve the others: all hear the event, then the
  throw is rethrown (an `AggregateError` when several threw).
- A stop that returns a promise is not awaited by `release`; its rejection
  surfaces as an unhandled rejection (loud, never swallowed).

Users: `infra/file-watcher`'s directory-watch hub (`acquireDirWatch`),
`infra/git/checkout-watch`, the metrics source watch, and the conversation
edited-files rooms.
