# string-hash

Portable, non-cryptographic string hashes in plain JS (`Math.imul`, no
`node:crypto`, no `Bun.hash`), so every host of the resource runtime — the Bun
server, central and a browser page — computes the same value for the same
string.

- `hash53(str, seed = 0)` — cyrb53 as a non-negative safe integer. Seed 0 is the
  classic cyrb53, and its values are pinned: the resource protocol id
  (`resource-protocol`'s `PROTOCOL`) is built on them.
- `hashHex(str)` — two independently seeded `hash53`s, 28 hex chars (~106
  bits). The resource runtime's ETags.
- `hash64(str)` — both cyrb53 lanes whole, an unsigned 64-bit `bigint`. The
  resource runtime's default keyed-snapshot hash (the Bun hosts inject
  `Bun.hash.wyhash` instead, through `ResourceRuntimeOptions.snapHash`).

None defends against a forged collision; they tell contents apart.
