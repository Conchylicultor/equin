# smooth-clock

`createSmoothClockModel()` — a continuous clock over a time source that
advances in steps. Feed it readings (`observe(time, performance.now(), rate)`)
and read the smoothed time at any wall instant (`at(perfMs)`); `reset()` forgets
the fit so the next reading snaps.

- A new reading never jumps the clock: the line re-bases where it is now and
  slews toward the reading at most `SMOOTH_CLOCK_MAX_SLEW` (5 %) of the rate.
- A disagreement past `SMOOTH_CLOCK_SNAP_SEC` (150 ms) is a seek: it snaps.
- A repeated reading carries no news and is ignored, so the clock keeps
  extrapolating — the caller must `reset()` (or stop reading) when the source
  STOPS (a pause, a suspended context), or the clock runs on without it.

Users: the YouTube media clock (`integrations/youtube`, the iframe's posted
playhead) and Sonata's audio engine (`AudioContext.currentTime`, which steps
per audio buffer and made the piano roll stutter).
