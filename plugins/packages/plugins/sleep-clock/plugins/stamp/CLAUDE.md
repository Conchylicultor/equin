# stamp

The one way to judge a stored instant's age on awake time. A `ClockStamp` is a
wall instant plus the machine's sleep clock at it (`SleepStamp`: boot +
cumulative time asleep); `awakeBetween(from, to)` is the span between two
stamps with the sleep taken out (`{ wallMs, sleptMs, awakeMs }`), whichever
processes took them. `sleptBetween` gives the sleep alone; `isSleepStamp`
checks a parsed JSON value.

Pure and web-safe (no `bun:ffi`), so a stored stamp is compared anywhere — a
web-reachable core (host-admission's) included. Reading one is
`packages/sleep-clock`'s `clockStampNow()` / `sleepStampNow()`.

Used by: host-admission's fleet-memory lease, main-slots' slow-drain judge,
boot-events' start lines (the boot watchdog). When to use it rather than an
awake timer or `sleptDuring`: the table in `packages/sleep-clock/CLAUDE.md`.
