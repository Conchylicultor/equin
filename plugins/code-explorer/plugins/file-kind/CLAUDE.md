# file-kind

`fileKindOf(path)` answers what a changed file is — `code`, `test`, `doc` or
`generated` — from its repo-relative path alone, so a diff list (the commit
pane's file DataView) can filter and group by kind without asking the server.

Precedence is `generated` > `test` > `doc` > `code`: a generated doc
(`docs/plugins-details.md`) is generated, not a doc. Each rule reuses its owner
instead of re-spelling it:

- generated — `isGeneratedArtifactPath` (`tooling/codegen/generated-artifacts`),
  the list `.gitattributes` is held equal to;
- test — `isTestFilePath` (`tooling/test-layout`), plus Go's `_test.go`;
- doc — `*.md`.

`FILE_KINDS` is the closed list in display order, with a label and an icon per
kind.
