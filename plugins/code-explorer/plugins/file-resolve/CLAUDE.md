# file-resolve

Fuzzy file path resolution for partial file links. When a file-peek pane receives a path that doesn't exist at the worktree root, this plugin searches `git ls-files` for matches using segment-subsequence matching and either auto-navigates (single match) or shows a disambiguation picker (multiple matches).

Example: clicking `task-detail/panes.tsx` resolves to `plugins/tasks/plugins/task-detail/web/panes.tsx` because the query segments appear in order within the full path's segments.

A path that names an existing file answers `exact` with where its bytes live: `git` with a worktree-relative path when the file is inside the worktree (an absolute or `~` path there comes back relativized), `host` with the absolute path otherwise. `useResolvedFile` hands back the matching file-viewer `FileRef`, so a peek of a file outside the worktree reads through host-fs — `code.file` / `file-viewer.bytes`' workspace arm and the `/image` route read only checkout-relative paths.

The answer is the live value `code.resolve-file` (`resolvedFile`,
`shared/resolved-file.ts`; served by `machine/`, `needsMachine`; there is no
route): `{ worktree, path }` →
`not-found` · `exact` · `resolved { matches, total }` — the candidates capped
at `RESOLVE_MAX_MATCHES` (200; a short query matches thousands of files),
`total` counting them all. Any workspace kind: a scratch workspace (not a
git checkout) answers `exact` for a path naming an existing file and
`not-found` otherwise — it has no `ls-files` to match against. On demand,
invalidated while read from a watch of the entry the path names and, in a
checkout, the checkout watch (a file created or removed, the git dir, a
`.gitignore` edit — which can un-ignore files no create announces), throttle
1 s. Refused: `no-workspace`. `useResolvedFile` reads it with `useLive` and
maps it onto a `ResolvedFileState`: a failed or refused resolution is its
`error` arm (carrying the read, so the pane offers Retry) and a host without
the computer its `unavailable` arm — never collapsed into `not-found`. `FileDisambiguation`
takes the `total` and says when the list is capped.
