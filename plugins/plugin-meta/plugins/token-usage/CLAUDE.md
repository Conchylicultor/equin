# token-usage

Which theme tokens a plugin's source paints with, and which plugin owns each
one — the two halves the `cross-refs` facet joins into `tokenUses`, which
`closure`'s `classifyEdges` turns into hard edges. A plugin that styles with
`bg-categorical-1` therefore bundles `ui.tokens.categorical` exactly as if it
imported it, and `served-baseline` lists no token group.

- **Ownership** — `tokenGroupsDeclaredIn(source, file)`: each
  `defineTokenGroup("<id>", schema)` call, read statically (the facet runs over
  source, before any barrel can be imported). The schema is an object literal,
  inline or a same-file `const` (`satisfies` / `as` unwrapped); anything else
  throws, never silently drops a group. Vars are `tokenVarName(key)`
  (theme-engine core), the rule `defineTokenGroup` applies at runtime. The
  `token-group-vars-in-sync` check holds this reading equal to the imported
  descriptors and requires the declaring plugin to be the registering one.
- **Usage** — `tokenVarsUsedBy(root, groups)`: per group of files (one per
  plugin), every var its text reads — literal `var(--x)` plus the vars of each
  Tailwind class, resolved by Tailwind itself: oxide extracts the candidates
  (ONE batch over every group — per-group scans cost ~2 ms of fixed overhead
  each), the design system loaded from app.css (`APP_STYLESHEET_PATH`, ui-kit
  core) compiles them, and the classes that read a var are attributed back to
  their groups by an exact-text match. Compiled candidates are memoized per
  app.css text, so a later tree build in one process compiles only new ones.

`@tailwindcss/node`'s `__unstable__loadDesignSystem` is the API IntelliSense
and prettier-plugin-tailwindcss use. Its packages share the range the CSS pass
(`web-artifacts`, `ui-kit`) declares, so one Tailwind resolves for both — the
scanner reads classes exactly as the shipped stylesheet is generated — and
`core/token-usage.test.ts` pins the resolutions that matter (an `@theme inline`
alias, an opacity modifier, a variant, an `@utility`), so an upgrade that
changes them fails a test rather than an edge.
