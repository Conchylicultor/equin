# key-width

`keyWidths(input, producers)`: for each record producer module, how many
modules its key covers (its whole closure — see the parent's *A producer's key
is its whole closure*) against how many it can call, walking pure re-export
modules (barrels) only to the modules defining the names it imports. Unsound
as a key, by design: it is the diagnostic that names each barrel import
dragging in code the producer never calls. `describeWideKeys` turns the
producers over `MAX_UNUSED_KEY_MODULES` into a check failure.

Its checks live with the producers' owners (`plugin-records/check` for file
scans, `plugin-tree/faceted/check` for facets and the harness), never in the
build path.
