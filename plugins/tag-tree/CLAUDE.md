# tag-tree

One nested-tag system for every plugin that lets the user organise its records
by a tree of tags (Prototypes, Places). Design:
`research/2026-10-21-global-tag-tree.md`.

## Mental model

- A **tag tree** is a per-plugin DB table of tags — name, parent, colour,
  icon, fractional rank, plus the tree's own extra columns. Each tree is its
  own table; trees never share rows. The field record, the table builder, the
  endpoints, the helpers and the picker are shared.
- A **carrier** is a row that references tags of a tree (a prototype's one
  `tagId`; a place's `tags` list). Carriers live in the owning plugin; the tree
  only knows how to rewrite them when a tag is deleted (`TagCarrier`).
- Positions are fractional `Rank` keys minted **by the server** over the
  complete sibling set, under a table lock. A client sends positional intent
  (`moveTag`'s body is exactly `useTreeModel`'s `onMove` destination), never a
  rank.

## Declaring a tree

```ts
// core/ — three literal declarations (the live key stays a literal for the scanners)
export const prototypeTagsEntityRef = tagTreeEntityRef("prototype_tags", { idKind: prototypeTagIdKind });
// The spec must be an INLINE object literal (the resource scanners refuse a
// call, so the engine ships no spec builder): pick ["name", …extras a list
// shows], carry every other field, id "id", all: { orderBy rank asc, unbounded }.
export const prototypeTags = liveCollection("prototypes.tags.all", { from: prototypeTagsEntityRef, pick: ["name"], carry: { pick: [/* … */] }, id: "id", all: { /* … */ } });
export const prototypeTagTree = defineTagTree({ id: "prototypes", entity: prototypeTagsEntityRef, collection: prototypeTags });

// server/internal/tables.ts — a load-order leaf
const prototypeTagsTable = defineTagTreeTable(prototypeTagsEntityRef);
export const _prototypeTags = prototypeTagsTable.table;

// server/ — serve the rows, register the tree with its carriers
contributions: [
  ...serveCollection(prototypeTags, { from: _prototypeTags }).declare,
  TagTrees.Tree(serveTagTree(prototypeTagTree, { table: _prototypeTags,
    carriers: [singleTagCarrier(_prototypeState, _prototypeState.tagId)] })),
]

// web/ — pick a tag
<TagPickerPopover tree={prototypeTagTree} selected={tagId ? [tagId] : []} offerNone
  counts={counts} onPick={(id) => setTag(id)}
  trigger={<TagPathChip tree={prototypeTagTree} tagId={tagId} />} />
```

- The tree's id kind must mint from nothing (`stamped` / `uuid`): the server
  mints a new tag's id from the ref (`entity.idKind`).
- Extra columns go in `tagTreeEntityRef(…, { extraFields })`; each needs a
  `touchedBy` entry in `defineTagTreeTable` (tsc), and a client may set only
  the ones listed in `serveTagTree`'s `editableExtras`.
- `TagTree<Row>` is invariant in `Row` (its live collection is), so code that
  takes any tree is generic: `<Row extends TagRow>(tree: TagTree<Row>)`.
- Sibling names are unique (case-insensitive): a "New tag" button names its
  tag with `freeSiblingName("New tag", parentId, tags)`.

## Trees

- `apps/prototypes/plugins/state` — `prototypes` (`prototype_tags`); one tag
  per prototype (`singleTagCarrier`).
- `apps/places/plugins/places-core` — `places` (`place_tags`, rank column
  `tree_rank`); extras `googleTypes` (client-editable) and `role` (Been / Want
  to go, `refuseDelete`); a place carries a list (`placeTagsCarrier`).

## Sub-plugins

- `engine` — core (field record, declarations, endpoints, pure tree helpers,
  palette), server (table builder, registry, the one `/api/tag-trees/:tree`
  endpoint set), web (`useTagTree`, `useTagTreeActions`).
- `picker` — `TagPickerPanel` (pure), `TagPickerPopover` (wired),
  `TagPathChip`, `TagMark`; exhibits `tag-tree/picker`, `tag-tree/path-chip`.
