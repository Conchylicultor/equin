# help-menu

The ? button on the global action bar (`ActionBar.Item` "help", placed just
before Improve in `config/shell/action-bar/item.jsonc`) and its "Getting
started" popover. Plan: section 6 of
[`research/2026-10-22-global-hints-onboarding.md`](../../../../research/2026-10-22-global-hints-onboarding.md).

- **The button is `hintsHelpAnchor`.** It registers `useHintAnchor` and wears a
  primary ring while `useHintAnchorPulse` holds — the engine pulses it on every
  tour end and toasts that the tour lives here.
- **The rows are an open slot**, `HelpMenu.Entry({ id, label, component })`,
  ordered by `config/hints/help-menu/entry.jsonc`. An entry renders one
  `ControlPanel.Row` and calls `useCloseHelpMenu()` when its action should not
  leave the menu open.
- **Its own entries** go through the engine's API only: Replay the tour
  (`useTours()`'s `primary` → `startTour`, absent when none), Show tips again
  (`useResetHints()` over every `useHints()` id) and Read the guide
  (`openInBrowserTab`). **Ask equin how to…** is contributed by its own
  plugin, [`hints/ask`](../ask/CLAUDE.md) (a floating thread card), which files
  its runs under the **Help** task category — `HELP_CATEGORY_ID` in `core/`,
  registered by `server/`.
