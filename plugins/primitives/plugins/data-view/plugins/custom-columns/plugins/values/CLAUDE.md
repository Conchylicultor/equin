# custom-columns/values

The DB half of custom columns: per-row VALUES keyed by
`(dataViewId, rowKey, columnId)`.

- `data_view_custom_values` (`_dataViewCustomValues`) — the generic table. The
  parent's `custom` scoped column set joins it on a live collection.
- `customColumnValues` (`data-view-custom-values`) — one surface's cells as a
  live value, recomputed by the change feed on every write.
- `setCustomColumnValue` (upsert, delete on empty) and `deleteCustomColumnValues`
  (one column across a surface).

`server/` is `portable: true`: it touches only the DB, so it runs in the browser
host too (the `/demo` worker). The column DEFINITIONS are config
(`customColumnDefs`, the scoped set, the settings UI) and stay in the parent
`custom-columns` plugin, which imports this one — never the reverse, so this
child names nothing of its parent.
