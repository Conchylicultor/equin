# paste-images

Pasting, dropping or picking (the composer's "+") a file into a text editor
uploads it as an attachment and inserts an inline node. An image renders as
`AttachmentThumbnail`: a 64px `ViewerThumbnail size="chip"`
(`primitives/overlay/image-viewer`) that opens the full-window viewer. Any other
file renders as `AttachmentFileChip`, a `LinkChip` that opens through the first
`AttachmentSlots.Opener` contribution (the Files preview pane), else the raw file
in a browser tab. The task description's read-only display reuses both.

In an editor both nodes wear `TokenFrame` (`token-extension/node`): selected as
one object, never as characters, and removed by a hover-revealed ×.

The opener is a contributed HOOK and contributions arrive as the plugin tiers
load, so a chip restored from a draft can render before its opener exists. The
chip therefore renders each link source as its own component type — never pick
a hook conditionally inside one component.

## Plugin reference

- Description: File paste/drop/pick support for the text editor. Uploads files via the attachments primitive and renders them inline: an image as a thumbnail chip that opens the full-window image viewer, any other file as a file chip; AttachFilesButton is the composer bar's "+" picker. Keeps every attachment an unsent draft references alive on the server for as long as the draft lives.
