# follow-motion

The contract between `auto-scroll`'s stick-to-bottom surfaces and whatever
animates their content: `FOLLOW_MOTION_ATTR`, stamped on an element whose
animation or transition grows the content, so a following surface writes the
bottom every frame while it runs.

A leaf with no imports, apart from `auto-scroll`, because the animators sit
below it: `css/motion` stamps it (`<Arrival>`), and `css/ui-kit`'s
`OverlayPanel` imports `css/motion` (`useSizeMotion`) — while `auto-scroll`
imports `ui-kit`. Read from `auto-scroll` itself, it closed the cycle
`ui-kit → motion → auto-scroll → ui-kit`.
