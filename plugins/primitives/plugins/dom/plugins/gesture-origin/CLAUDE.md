# gesture-origin

`isChromeGesture(event)`: may a chrome surface act on the pointer gesture it
caught? A drag handle (the sortable-list pointer sensor) and a header's
double-click (the pane chrome's maximize) both ask before acting.

Not its own when:

- **it came through a portal** — React bubbles synthetic events up the
  component tree, so a press in a popover opened from a pane header reaches the
  header's drag listener. Containment is read on the DOM, where the popover is
  outside the header;
- **it landed in text entry** — an input, textarea, select or editable region,
  where press-and-drag selects and double-click picks a word.

A new chrome gesture (a drag, a double-click, a long-press on a bar) asks the
same question here rather than re-deriving it.
