# agent

The content side of the content-frame channel, as a leaf both ends import:
`protocol.ts` (the closed request/reply/event vocabulary, zod-parsed by the
parent) and `frame-agent.ts` (`installFrameAgent`, serialized into every content
document's `<head>` by `injectFrameAgent`). Its own plugin so the endpoints
primitive (which injects it into every `access: { content }` route's HTML) and
the frame primitive (whose web half imports endpoints) do not form a cycle.
The model and the rules live in the parent's CLAUDE.md (`primitives/embed/frame`).

- **Self-contained by construction**: `installFrameAgent` references nothing
  outside its body (the protocol id is passed in) — `frame-agent.test.ts`.
- It trusts nothing: a request it cannot read is an error reply; it touches
  only its own document's custom properties, scroll offsets and `resize`.
