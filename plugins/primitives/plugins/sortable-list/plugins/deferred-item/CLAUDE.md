# deferred-item

The drag-free half of [`sortable-list`](../../CLAUDE.md)'s deferred list:
`ItemBindingProvider` (one list's binding store), `DeferredSortableItem` (a box
that publishes its node by id and wears whatever drag props a host publishes
back) and `useItemBindingStore` (what a host binds against).

It imports no `@dnd-kit`. That is the point of it being its own plugin: closure
edges are plugin-level, so an item imported from `sortable-list`'s barrel would
ship dnd-kit with it. Reorder's at-rest layout renders every slot's items through
this plugin in every bundle; `sortable-list`'s `DeferredSortableHost` (the dnd-kit
half) is mounted beside them only by the layout editor, where it ships.
