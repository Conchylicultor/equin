# meter

The linear meter / progress bar: a fully-rounded track as wide as its
container, filled from the start to a fraction. Every plugin used to hand-roll
one (`<Clip className="h-1 rounded-full bg-muted">` + a `style={{ width }}`
div), each with its own height, track colour and fill.

```tsx
<Meter
  value={0.51}                 // 0..1, clamped when drawn (over 1 draws full)
  label="Week usage"           // aria-label (required)
  tone="default"               // default (accent) | warning | destructive | muted
  size="default"               // default (5px) | thin (3px)
  marker={0.32}                // optional target / pace tick
  markerLabel="An even pace through the week"
  role="meter"                 // meter (a measurement) | progressbar (a task's progress)
/>
```

- **Tone is what the reading means**, not a colour: `default` is the accent as
  text (`primary-text`, readable on any surface), `warning` amber,
  `destructive` coral, `muted` for a neutral share. A caller maps its own
  levels onto it (`UsageLevel` → tone).
- **Width is the container's.** The meter is `w-full`; size it with layout
  primitives or `className` (`w-16`, `rigidClass()`). Thickness is `size`, a
  closed scale — never a height class.
- **The track is a translucent ink** (`bg-foreground/10`), never a palette fill:
  it is a step off whatever it sits on (canvas, sidebar, popover, a selected
  row), where `bg-muted` vanished on a popover whose tone is `--muted` (Mist).
- **The track never clips**, so the marker (1.5px, ~45% foreground) overhangs
  it by 2px each side (1.5px on `thin`).
- `aria-valuenow` is the drawn percentage; pass `valueText` when the reading is
  better said in words ("120 GB of 500 GB").
- A caller that wants a non-zero reading to always show a sliver floors its own
  `value` (`calls > 0 ? Math.max(f, 0.015) : 0`) — the meter draws what it is
  given.
