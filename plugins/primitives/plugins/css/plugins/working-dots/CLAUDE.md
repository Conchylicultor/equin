# working-dots

`<WorkingDots />` — three dots that say "an agent is working", moving the
way something alive does rather than looping a keyframe.

## Design

- **Shapes** (`web/internal/shapes.ts`) are pure functions of one pass's
  progress `p` (0 → 1, may overshoot): each dot's offset from the resting row.
  Every shape starts AND ends on the resting row (leap ends with the dots having
  traded places, which looks the same), so any pass can follow any other with no
  seam. `shapes.test.ts` holds that invariant.
- **Engine** (`web/internal/engine.ts`) drives one requestAnimationFrame loop
  per instance and writes transforms straight to the dots (no React render per
  frame). Per pass it varies duration, amplitude and the leader/follower lag
  through smooth value noise; each dot follows a slightly under-damped spring
  chasing an eased target (starts from rest, settles with a faint overshoot);
  fast dots stretch along their path; between passes it holds for a varying
  time with a faint out-of-step breath. Rhythms are keyed to where a dot IS,
  not which element it is, so leap's hand-over never pops.
- **One mix, no modes.** Every style (gooey, wave, leap, orbit, ring, glow) is
  in the pool, picked uniformly at one fixed energy (speed, amplitude, hold
  length). Never the same style twice in a row; a style repeats 1–3 times
  (orbit and ring once).
- **Alive to the pointer.** *Sniff*: the dot nearest a pointer that is right
  at the row (a few px — never from across the line) reaches toward it,
  tentatively, never past it; a pointer left still is minded less. *Poke*:
  pressed, the row huddles; released, it answers with a reaction drawn by
  weight and never the same twice running (`web/internal/reactions.ts`:
  scatter, hop, gulp, shiver, bolt, spin) — pure kick lists to each dot's
  wobbly jolt spring. A poke cuts the pass short by handing each dot's pose to
  its jolt spring (no seam) and leaves excitement behind: faster moves,
  shorter holds, a glow, bigger reactions on quick repeats. When leap ends
  with the dots traded, each dot's spring state moves with it to the element
  now in its place, so a jiggle or a reach never pops.
- **One rendering for every style.** The dots always draw through the goo
  filter (blur + alpha threshold), which also shaves a small dot's edge — so a
  style drawn without it would show bigger dots. Halos sit on their own
  unfiltered layer under the dots, following them, so the threshold cannot
  turn a soft halo into a solid blob.
- The loop pauses while the dots are off screen (`useInView` — a
  keep-alive tab hidden with `display: none` keeps its rAF running otherwise),
  and does not start under `prefers-reduced-motion` (a still row).

Size follows the ambient `ControlSize` (no prop), like `BouncingDots`. Colour is
`currentColor` (primary-text by default; pass a text-colour class to override).

Prototype it came from: `proto-1792522706-rgo0gx`.

`<WorkingText>{label}</WorkingText>` is the words beside the dots: a highlight
sweeps across them, and a new label slides in (keyed by its text). It is an
inline span, so the caller's `<Text>` keeps the type role and its line keeps the
truncation.
