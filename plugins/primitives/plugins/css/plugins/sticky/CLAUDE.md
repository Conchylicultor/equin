# sticky

The sticky-positioning box — pins a header/footer/sidebar to a scroll edge with
a z-layer-aware stacking level. ~24 call sites wrote `sticky top-0 z-raised` by
hand.

## Layer vocabulary, not raw z

The `layer` prop is an `InTreeLayer` (`base | raised | nav | float | overlay`)
from the shared `z-layers/web` resolver, and the name→`z-*` class is resolved
through that one source via `zLayerClass()`. A sticky element is never a raw
`z-<n>`.

## Offset is an inline style

The semantic spacing ramp defines no inset (`top-*`/`left-*`) utilities, so a
non-flush `offset` is applied as an inline style reading the density `--space-*`
var (the `Grid`-style escape for what a class can't express). `offset="none"`
(the default, and the norm for a sticky header) is a literal `0`.

## Scope

Owns position + edge + stacking, plus the opaque **mask** (`mask` prop →
`bg-chrome-mask`). Borders and blur stay in `className` (`border-*` /
`backdrop-blur` are not banned).

## Masking — follow the surface, never hardcode `bg-background`

An opaque sticky header has to hide the content scrolling under it. Do that with
`<Sticky mask>`, not a hand-written `bg-background`. `mask` paints
`bg-chrome-mask`, which resolves to the `--chrome-mask` var — and every surface
co-publishes its own background there (the page canvas by default via `:root`,
`--sidebar` in the app-shell sidebar, a `<Surface>`'s own color when nested in
one). So the bar masks with *whatever surface it is pinned inside* and can never
become a mismatched band in a tinted surface (the sidebar/inset-framing bug).
`className` still composes last, so a bespoke case can override the color. A new
tinted surface only has to set `--chrome-mask` alongside its background to get
matching pinned bars for free.

## Fading — `mask="fade"`

`mask="fade"` is the opaque mask plus a tail: the band keeps `bg-chrome-mask`
and the `sticky-fade` utility (app.css) hangs an out-of-flow `::after` gradient
from `--chrome-mask` to transparent past the band's pinned-away edge, over the
density `--sticky-fade-tail` (default 1.75rem). Content scrolls UNDER the band
and dissolves into it instead of vanishing at a hard line. The tail is
absolutely placed off the (positioned) band, so the band's measured height —
what `stickyOffsetPx` stacks the next band at — never includes it, and it takes
no pointer events. Sticky writes `data-sticky-edge` so the tail hangs the right
way for every edge; an inactive band draws no tail (it would hang off whatever
positioned ancestor is above). Pure map: `stickyMaskClasses`. Caveat: like any
absolute box, a tail hanging past the END of a scroller's content adds to its
scrollable overflow — a band normally has content beyond it, so this only shows
on a near-empty list.

## Offsets from a measured height — `stickyOffsetPx`, never `Math.round`

A box pinned under another (a group header under a toolbar, the next header in
a stack) pins at the measured height of what is above it. Turn that height into
the offset with `stickyOffsetPx(height)`: it snaps to the layout engine's 1/64
px unit, which keeps sub-pixel jitter from re-rendering without introducing
error. `Math.round` does introduce it — a 29.5px band rounded to 30 pins the
next box half a pixel low, and the content scrolling behind shows through that
strip.

## Conditional stickiness — toggle, don't swap

To make an element sticky only some of the time, set **`active={false}`** rather
than rendering a different element when it shouldn't stick. `active=false` drops
the position/offset/z-layer but keeps the *same* element — so toggling never
changes element identity and therefore never remounts the children. Swapping
between `<Sticky>` and a plain `<div>` instead would unmount the subtree on every
toggle, silently resetting any child component state (e.g. an inner
`Expandable`'s expanded flag).

## Props

- **`active`** — whether positioning is applied. `false` renders in normal flow
  as the same element (no remount). Default `true`.
- **`edge`** — `"top"` (default) | `"bottom"` | `"left"` | `"right"`.
- **`offset`** — `SpaceStep` inset from the edge. Default `none`.
- **`layer`** — z-layer stacking level. Default `raised`.
- **`mask`** — `false` (default) | `true` (opaque `bg-chrome-mask`) | `"glass"`
  (frosted) | `"fade"` (opaque + a gradient tail, above).
- **`as`** — host element. Default `div`. **`className`** composes last; caller
  **`style`** overrides the edge offset.
