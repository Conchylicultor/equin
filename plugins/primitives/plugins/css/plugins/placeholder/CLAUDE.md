# placeholder

Declares only its block padding (`py-sm`). Its inline edge is the region's, like any
content: a padded region's rail, or the rows' text edge in a row host
(`rail-text-indent` = text rail − rail). It never pays the rail, so a Placeholder
with nothing padding it sits flush — give that spot an owner (a region; a
state standing in for a pane's content is a `PaneMessage`, on the pane header's
edge), never an inset on the Placeholder. Its `py-sm` is its own vertical room:
an owner around it adds no block padding of its own. Not `rail-follow`:
nested followers would pay twice. A centred empty state is `<Center>` around it
(block rhythm only, e.g. `py-xl`); a failed read is `ResourceErrorInline`.
