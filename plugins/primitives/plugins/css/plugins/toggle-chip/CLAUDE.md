# toggle-chip

## Passthrough: `ref` is the chip, not its label

A toggle chip IS a `Badge`, so `ref` and everything else you spread land where
Badge's do — the chip shell (a `<button>` by default), never the `truncate` span
inside it. `ref` is newly typed; it was already flowing untyped through the old
anonymous index signature. See
[the passthrough contract](../../../passthrough/CLAUDE.md).

## `SegmentedControl variant="underline"` is not a chip

Every other variant is a `ToggleChip` colour treatment. `"underline"` is a tab
strip: bare segments (icon · `Text variant="control"` label · count) on the
group's `border-b` hairline, muted until selected; the selected one's underline
is a decorative child bar pulled `-bottom-px` onto that hairline, so the two
read as one rule (a child, not `::after`: `no-adhoc-control` reads a pseudo's
`after:h-* after:rounded-*` as the button's own geometry). Its height sits one notch above the control scale for the ambient
density (`md` → `control-lg`). A segment's optional `count` draws a filled
`Badge` pill after the label in every variant.
