# card

The sanctioned home for **card chrome** — the `raised` surface role plus card
padding. `<Card>` is now a thin `<Surface level="raised">` wrapper (see the
`surface` primitive): the `rounded + border + bg-card + shadow` chrome and the
Ctrl+A **select-scope** live in Surface, and Card layers on `p-card` and the
interactive/selected affordances. A click into the card + Ctrl+A selects only the
card, not the surrounding pane, with zero per-consumer wiring. Card padding is
the density `p-card` token (`--pad-card`), so it tightens with the active density
preset (Comfortable / Cozy / Compact) like every other padded chrome surface.

- Polymorphic `as` (`div` | `button` | `a` | `li`, default `div`); `ref`
  forwards to the root DOM element (DnD consumers depend on it).
- `interactive` adds the hover affordance; `selected` adds the emphasis border.
- Default chrome is `rounded-card border border-border bg-card shadow-sm p-card`
  (`rounded-card` = the shape group's `radiusCard`, default the `rounded-md` step); pass
  `className` to override (cn uses `tailwind-merge`, so `rounded-lg` /
  `bg-muted/30` / a different padding cleanly replace the defaults).

The `surface/no-adhoc-surface` lint rule (in the `surface` primitive — it
subsumed the former `no-adhoc-card`) fingerprints ad-hoc raised-surface markup
(rounded + border + the `bg-card` token + padding on an intrinsic
`div`/`button`/`a`/`span`) and redirects it here. It keys on `bg-card`
specifically — the dedicated card-surface token — not the broader `bg-muted`/
`bg-background` that panels, rows, and chips use without being cards. Escape via
`<Card>` / `<Surface>`, the `p-card` token, or
`// eslint-disable-next-line surface/no-adhoc-surface -- <reason>`.

`Card` takes an OPT-IN `controlSize` prop that declares the control density for its contents; omitting it means controls inside inherit from the ambient `ControlSizeProvider` (no change). Note that `controlSize` is the ControlSize axis (button/chip/badge height tier), which is distinct from the `p-card` density-preset axis (padding tightness).

## Passthrough

`ref` and every prop `Card` does not name land on the root element — the one
`Surface` renders. See
[the passthrough contract](../../../passthrough/CLAUDE.md).
