# grid

The responsive / uniform grid primitive. A wrapping grid of **equal-width
cells** that reflows by available width — galleries, launcher grids, card
collections. Pick **one** of: the minimum cell width (`minCellWidth`, responsive,
cells stretch), a fixed column count (`cols`), or the exact cell width
(`cellWidth`, cells never stretch, row centred) — the three are an **xor**
discriminated union — and the track function does the rest.

## Why this is a closed prop surface, not a `grid-template` passthrough

The structural `rigid | flexible | rigid` row — the case that used to be
hand-rolled with per-call-site `flex-1` / `min-w-0` / `shrink-0` — is **Frame's**
job. Grid owns the one remaining layout concern with no other home: a grid of
uniform cells. An arbitrary `grid-template` string *is* the raw CSS the layout
standard bans, so Grid deliberately exposes no `columns` escape hatch. The two
real needs are covered (structural → `Frame`, uniform responsive → `Grid`);
anything rarer stays a per-site `eslint-disable … -- <reason>` exception.

## The track function

`gridTemplateColumns(opts)` is the single source of truth — exported so the
component and the pure test share one definition. Its parameter is the same
`{cols}` xor `{minCellWidth, mode}` union as the component, so the two
mutually-exclusive paths can't be conflated:

| Path                  | Output                                            | Behaviour                                                       |
| --------------------- | ------------------------------------------------- | -------------------------------------------------------------- |
| Fixed (`{ cols }`)    | `repeat(<cols>, minmax(0, 1fr))`                  | exactly N equal columns                                        |
| Responsive `fill`     | `repeat(auto-fill, minmax(<minCellWidth>, 1fr))`  | stable column count — keeps empty trailing tracks              |
| Responsive `fit`      | `repeat(auto-fit, minmax(<minCellWidth>, 1fr))`   | collapses empty tracks so present cells stretch to fill the row|
| Fixed cell (`{ cellWidth }`) | `repeat(auto-fill, <cellWidth>)` + `justify-content: center` | exact-width tracks, leftover split on both sides (launcher grids) |

The `minmax(0, …)` / `minmax(<minCellWidth>, …)` min lets a track shrink without
forcing the row to overflow.

## Props

The two geometry props are an xor discriminated union — pass exactly one path:

- **Responsive path** — **`minCellWidth`** (required, `"12rem"`-style min width
  before a row wraps) + optional **`mode`** (`"fill"` default, stable columns |
  `"fit"`, stretch present cells). No `cols` allowed.
- **Fixed path** — **`cols`** (required, fixed column count). No
  `minCellWidth`/`mode` allowed.
- **Fixed-cell path** — **`cellWidth`** (required, the exact track width, e.g.
  `"116px"`). The path centres the row itself, so `justify` is not allowed
  either.

Shared (both paths):

- **`gap`** — spacing-ramp step. Default `md`.
- **`align`** / **`justify`** — `StackAlign` / `StackJustify` (items / content).
- **`as`** — host element. Default `div`. **`className`** composes last.
