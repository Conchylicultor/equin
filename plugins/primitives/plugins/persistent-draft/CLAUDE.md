# persistent-draft

Drafts over a `web-storage` store. The caller declares the store — its owner,
cap, TTL and area — with `defineStore` (`primitives/dom/web-storage`), usually
`whenFull: "refuse"` since a draft is what the user typed, and hands the handle
to these functions:

```ts
const promptDrafts = defineStore({
  owner: "conversations.prompt-draft", label: "Prompt drafts",
  area: "local", cap: "1 MB", ttl: DEFAULT_DRAFT_TTL, whenFull: "refuse",
  schema: z.string(), legacy: legacyDraftKeys("conversation:prompt"),
});
const [text, setText, clear] = useDraft(promptDrafts, "", { scope: convId });
```

`useDraft` is the reactive `useState` drop-in; `readDraft`/`writeDraft` are the
render-free twin over the same store, for callers writing at input frequency (a
scroll offset, a caret position) where a render per write would be absurd.

A refused write is never silent: the store announces it (a toast once per owner,
a report, the health report's Browser storage row) and the value stays in
memory. `legacyDraftKeys(<old key>)` is the `legacy` of a store taking over
drafts written before web-storage (`singularity:draft:<key>[:<scope>]`); it
carries them over, so no unsent text is lost — drop it once browsers migrated.
