# diff-view

Generic side-by-side / text diff renderer. The domain-agnostic diff-rendering closure: `TextDiff` diffs two in-memory strings, `DiffView` / `DiffOrImageView` diff a worktree file against a git ref (with image-aware side-by-side), and `DiffRenderer` plus the shiki token helpers back both. `DiffView` reads everything live through `useLive`: the diff from code-api's `code.file-diff`, and both sides' whole text from `code.file` (one list read) — the old side's text gives the expandable context lines, both give the syntax tokens; an expansion is dropped when a live change moves the hunks or the text under it. This is a pure library primitive with no contributions — file-pane's `diff` plugin is a thin adapter that registers it as a `FilePane.Renderer`.
