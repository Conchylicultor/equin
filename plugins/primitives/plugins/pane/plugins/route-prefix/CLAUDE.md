# route-prefix

A **route prefix** is a leading address-bar segment that belongs to no app's
route but to the surface mode showing it: the desktop's `/desktop`, written in
front of the focused window's own URL (`/desktop/agents/c/42`; bare `/desktop`
is the desktop with nothing open). Design:
`research/2026-10-24-global-desktop-url-prefix.md`.

- **Known prefixes** (`setRoutePrefixes`, installed by `apps-core` from every
  surface-mode `Apps.App` entry's base path): every read strips the one the URL
  carries — `pane`'s `currentRoutePath()` returns the plain app route, so
  routing below never sees it; `currentRoutePrefix()` (pane) says which one the
  address bar carries.
- **Active prefix** (`setActiveRoutePrefix`, set by `apps-core/tabs` from the
  current surface mode): put back by every URL writer — the shell history
  adapter's `commit` — and by `openInBrowserTab` in front of an in-app path, so
  a link opened elsewhere comes up in the same mode.

A leaf (no imports), so `pane` and `link-gesture` — which `pane` imports — both
read it.
