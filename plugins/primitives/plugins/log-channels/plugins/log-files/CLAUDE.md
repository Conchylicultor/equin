# log-files

The desktop's log-channel files: where each worktree's `<channel>.jsonl` lives
(`logsDir()` for this process, `logsDirFor(worktree)` for any), the bounded read
path (`readChannelEntries`, `readChannelJson`, `readChannelJsonAsync`,
`listChannels`) and the `client-log` family bound (`clientLogFamily`) that makes
the browser's open-ended channels enumerable in `getFileSinks()`.

Desktop-only — it reads the filesystem — and split out of `log-channels` so the
channel registry stays portable: the WRITE half is `log-channels#machine` (the
`LogPersistence` provider), the read half is here, for the Debug tools that read
another worktree's logs. See `plugins/primitives/plugins/log-channels/CLAUDE.md`.
