# documents

The user's **Documents**: files equin keeps itself rather than somewhere on
the computer's disk, so they exist on every host. Files' one data dir
(`apps/file-explorer`, declared by the app root's `data-dirs/`) as a
`data-files` root (`documentsFiles`, `server/`), bound on the desktop by
`machine/` and held in memory — kept in the browser's storage — by a browser
host. It is `browse`d, so the explorer's App data place lists it as
"Documents" and opens its files in the file viewer, read-only.

`writeDocumentsFixture(fixture)` (`server`) writes a fixture (path → bytes or
text) through the root's own writes: the in-browser demo's seed fills the
demo's Documents with it (`apps/website/demos/workspace`'s `data/documents/`).
