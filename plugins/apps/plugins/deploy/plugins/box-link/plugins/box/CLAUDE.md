# box-link/box

The box half of the [box link](../../CLAUDE.md). Ships wherever a mirror set
ships: `site-mirror/box` (itself a companion of `table-mirror/source`) imports
this server barrel to contribute its signal, so every composition with a
mirror set serves the stream — the website on its box, and the local app,
whose own stream a demo's stand-in box is read through.

- **`server/`** (portable) — `BoxSignal({ source, subscribe(emit) })`: a
  signal source the stream relays. `subscribe` resolves to the unsubscribe
  once listening (resolve-then-read), `emit(payload)` sends `{ kind:
  "signal", source, payload }`; the payload is the source's own vocabulary,
  parsed by its consumer on the computer (`onBoxSignal`). A source coalesces
  its own storms. Collected generically: the stream never names a
  contributor.
- **`machine/`** — `GET /api/host-only/box-link/stream`, behind `hostOnly`
  (Caddy 404s it publicly too), a raw NDJSON stream (`ndjsonResponse`,
  `machineHandler`). Per stream: subscribe to every `BoxSignal` FIRST, then
  `hello` (so a change after the reader's catch-up pull is always
  signalled), then a beat at once and every 15 s (inside Bun's 60 s idle
  timeout). On abort (the reader left) every subscription and the beat timer
  are released.

## Host metrics (`machine/internal/host-metrics.ts`)

- **CPU** — busy share of all cores since the stream's PREVIOUS beat, `null`
  on its first. Linux: the aggregate `cpu` line of `/proc/stat` (iowait
  counted idle, steal counted busy — a VPS's stolen time is time the box did
  not get). Elsewhere (a macOS stand-in box): the `os.cpus()` tick counters.
  `cores`, `load1` from `node:os`.
- **Memory** — `packages/host-memory`'s `readHostMemory`: in use = total
  minus what the system can hand out. An OS it cannot read throws (the
  stream ends loudly, never made-up meters).
- **Disk** — `statfs` on the install (`REPO_ROOT`), df's arithmetic.
- **Build** — `buildId` is the commit the served bundle was built from
  (`build/server-build-id`'s `getServerCommit`), `null` when the dist names
  none.
