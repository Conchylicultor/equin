# site-mirror

The table mirror ([`database/table-mirror`](../../../../../database/plugins/table-mirror/CLAUDE.md))
between a deployed site's box and this computer. Design:
[`research/2026-11-12-global-table-mirror.md`](../../../../../../research/2026-11-12-global-table-mirror.md)
§ Deployment glue. Split like `host-only` / `host-query`, so the box half never
pulls in SSH:

- **`core/`** — the four host-only route contracts both halves speak
  (`GET /api/host-only/table-mirror/{changes,copy,keys,rows}?q=<base64url>`,
  each answering a page or a `MirrorRefusal`), the question bound
  (`MIRROR_QUESTION_MAX_CHARS`, 12 000) and the answer cap
  (`MIRROR_ANSWER_MAX_BYTES`, 16 MB: four times a page's 4 MB of row JSON, for
  the envelope).
- **`plugins/box`** — ships on the box: the routes over the source's readers.
- **`plugins/pull`** — local only: replicas, the transport, the jobs, the sync
  endpoint, the `SiteMirrorSink` contribution (a set read through its owner's
  sink at its own pace — site-reports), the status value and the freshness
  line.
