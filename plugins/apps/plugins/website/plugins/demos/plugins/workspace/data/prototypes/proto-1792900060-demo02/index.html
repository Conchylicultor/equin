Why does the drag test fail on CI but not locally?
Agent · 6m ago

I traced it to a timing issue. The test dispatches pointerdown and immediately reads the tab order, but useRankSortableItem only commits the new rank after the drop animation settles — about 150 ms on CI, where the runner is slower.

There are two ways to fix this:

  • Wait for the reorder.committed event in the test instead of reading the DOM right away.
  • Commit the rank optimistically on drop and let the animation play over the already-reordered list.

The second option is cleaner: it removes the window entirely, so no other caller can observe the stale order either. It touches the shared reorder primitive though, so every sortable list in the app would pick it up.
