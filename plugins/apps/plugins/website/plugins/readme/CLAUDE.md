# readme

The repo README's images, generated — never drawn by hand. README.md (at the
repo root) is written prose; the three pictures it shows are SVG files in
`docs/readme/`, rendered from the same sources the app and the site draw from:

- `hero.svg` — the banner: the logo drawing itself in (`ui/logo`'s
  `logoMarkSvg` with `draw`, the brand's one motion), the name and tagline, and
  a living plugin network beside it (it builds itself, then drifts, sprouts and
  withers leaves, and carries a faint signal).
- `apps.svg` — the app shelf: the website apps catalog
  (`website/pages/apps` core, apps not built yet left out), each app its
  website tile (`website/app-tiles` colours, its Material Symbols glyph).
- `demo.svg` — the Try it card, linking to the live demo.

They are shown through GitHub's `<img>`, so each is self-contained: no script,
no web font, CSS animations only (all stop under `prefers-reduced-motion`,
except the network's slow SMIL drift). One dark look for both GitHub themes.

## Changing them

1. Edit `core/internal/*.ts` (or the logo, the catalog, the tile colours).
2. `./equin run plugins/apps/plugins/website/plugins/readme/scripts/render.ts`
   rewrites `docs/readme/`.

`readme:files-in-sync` fails until step 2 is done: each file must equal what
`README_FILES` renders now.
