# ask

Ask Sonnet: a question in the Places search bar launches a background
conversation under the `places.ask` scratch profile, shown as an
`<AgentThread>` (agent-thread).

- **Research, then Maps.** The agent may use WebSearch / WebFetch (allowed in
  the profile; the session runs in bypass mode, so only `deny` removes a
  tool): web sources find better places and say why they are worth it; Maps
  (`places_search_text`) supplies the facts and the only ids a pick may name.
  It reads the area's name off its first search's addresses — the input has
  only bounds (no reverse geocoding).
- **A pick** (`PlacesPicksSchema`): `googlePlaceId`, `why` (one line of
  checked facts), `about` (1–3 sentences, ≤ 400 chars) and `sources` (≤ 3
  `{ title, url }`). `about` is `.optional()` in zod ONLY so picks stored
  before it existed still parse — the tool refuses a new call without it.
- **Follow-ups keep earlier picks.** The newest `places_show_picks` call is the
  map's set; earlier ones stay in the thread, collapsed. A question about
  shown places is answered in text; a narrowing re-includes the picks that
  still fit.
