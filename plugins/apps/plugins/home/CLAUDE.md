# home

Entry-point app: a phone-home-screen launcher of every installed app, shown at
`/home`. The root path `/` redirects here.

- **The grid** (`app-cards`) is a `data-view` rendered in the `icons` view: one
  tile per registered `Apps.App` (read through the generic
  `Apps.App.useContributions()` collection API, minus Home itself), with the
  app's name underneath. The tile is the row's leading avatar field
  (`avatarFieldDef`, `shape: "squircle"`) drawn in the avatar's flat `tile`
  presentation: the app's declared icon colour, or one derived from its id when
  it declares none (Settings declares `slate`, so it reads grey). Clicking a
  tile replaces the Home tab's app with that app. Dragging a tile reorders the
  grid; the order persists per view through the data-view `view-order`
  contribution.
- **The toolbar** is the `capsule-toolbar` arrangement (`toolbar={capsuleToolbar}`):
  one centred pill holding the collapsed view switcher chip ("Apps ▾", whose
  menu also opens View settings), the search field (`/` focuses it, Escape
  clears and leaves it), the filter / sort / view-settings circles, and the
  round New app button. Below 560px of capsule width the three circles fold
  into one control; below the DataView's own compact breakpoint the capsule
  gives way to the standard compact fold.
- **Panes** — Home is a full-pane surface (`shell`'s `HomeLayout`): the
  launcher is the index pane (`homeRootPane`, `/home`), and New app
  (`new-app`, `/home/new`) replaces it. Routes live in `shell/core/routes.ts`.
- **New app** — the capsule's button, the grid's trailing dashed "New app"
  tile (the icons view's `addTile`) and the no-match empty state's "Build
  one?" all open the New app screen (`new-app`): one prompt that files a task
  under the Apps category with a deliberately minimal prompt ("I want to build
  a new app. Create a prototype first." + the description) and opens its
  conversation in the Agent Manager. The repo's own instructions —
  `prototypes/CLAUDE.md`, the `create-app` skill — tell the agent how, so the
  prompt does not restate them. Design: proto-1792811301-yksedx.
- **Theme** (`shell/web/internal/theme.ts`) — Home contributes its own theme via
  `ThemeEngine.Theme`: a black page and an ocean categorical palette for the
  tiles. `config/ui/theme-engine/@app/home/theme.jsonc` selects it for the
  `app:home` scope only, so avatars and chart colours in other apps are
  unchanged.
- **Layout** (`shell`) — a centred "Apps" title and subtitle above the grid
  section, in one column `min(920px, 100% − 40px)` wide.
