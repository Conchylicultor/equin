# icons

The agent manager's own icon family, `agentIcons` (`core/agent-icons.ts`):
the line glyphs of the agent-icons prototype (`proto-1789643584-ldt6`), each
with a small one-shot motion (`data-motion`, the icons primitive's closed
`ICON_MOTIONS` vocabulary) that plays on hover inside a motion region — the
app-shell sidebar. The Mist theme selects it (`iconFamily: "agent"`,
`agent-manager/shell/web/internal/theme.ts`).

- **Glyph names** are the prototype's Lucide-style names (`list-checks`,
  `bot`, …); **`symbols` keys** are the Material names the agent manager's
  chrome writes (`checklist`, `precision-manufacturing`, …). Map a Material
  name only when the drawing genuinely fits it.
- **Coverage is `fallback`** (to Lucide): an unmapped name draws Lucide, and
  Debug → Icons lists it. Flip to `strict` once that list is empty.
