# prototypes-nav

The agent manager's entry point into Prototypes: a `Conversation.ActionBar`
button, next to Pages, that opens the Prototypes gallery.

**Why it opens the app, not a column.** Pages' tree is a narrow nav list, so
`pages-nav` toggles it as a Miller column beside the conversation. The gallery
is a full-surface app index (a card grid over the canvas ground) and a card
opens the full-surface canvas, so it is opened rooted
(`openPane.link(prototypesGalleryPane, {}, { mode: "root" })`), which the pane
router hands to the cross-app navigator — the tab moves to the Prototypes app.
It is a real link: ⌘/middle-click opens it in a new browser tab.

Lives under `apps/plugins/agent-manager/plugins/` for the same reason as
`pages-nav`: app content, so it loads in the deferred tier.
