# source-field

The `source` dimension of every list of events: the events entity's `sourceId`
field (declared once, with its label, in events-core) presented with the live
configured sources as its options — `FieldPresentation.Register({ owner:
eventsEntityRef, fields: { sourceId: { useOptions } } })`. `event-list` names no
source and no source type; this plugin owns the option list because only it
holds the live `event_sources` rows.

The options are a READ (`useSourceOptions`: `mapResource` over the whole
`eventSources` set, sorted by name): loading until the sources land, never an
empty stand-in. Filtering stays on the raw `sourceId`, which the `events.list`
collection lists, so filter, sort and group compile to SQL.
