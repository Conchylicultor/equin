# launcher

The desktop's ⌘K launcher (mockup `#launcher`): a centred dialog over the
windows, contributed to `Desktop.Overlay`. An empty query shows the grid of every
app that opens in a tab (rail order, a dot on the ones with a window on this
desktop); a query shows the matching apps ("Switch to" / "Open") then the
matching commands. Enter runs the selection, Shift+Enter opens a new window,
Esc or a backdrop click closes, hovering moves the selection, and a right-click
on an app offers Open / New window / Keep in dock.

## Shape

- `web/internal/launcher-model.ts` — the pure part: `listLauncher` (what a query
  lists, in drawing order), `moveSelection` (arrow keys: grid ±columns / ±1, list
  ±1, clamped), `windowsByApp` (a window is of its ACTIVE tab's app). Tested.
- `web/internal/launcher-controls.ts` — `openLauncher` / `closeLauncher` /
  `toggleLauncher`. Visibility is the overlay's own React state; these reach it
  through an install sink the overlay fills while mounted, i.e. while the desktop
  is active. Calling one with no desktop up throws.
- `web/internal/use-launcher-commands.ts` — the Commands section.
- `web/components/` — the overlay (owns open state), the panel (query, selection,
  context menu) and the grid cell / rows.

## Commands are read, not restated

Window actions are NOT a second list. The launcher lists the registered
shortcuts whose `group` is `"Window"` or `"Desktop"` (label, keys formatted for
display, handler), de-duplicated by label (one action bound to two key
spellings lists once). Giving a window action a launcher entry is registering a
shortcut in one of those groups. Only the actions that have no key are listed
here (overview, tile all, minimise all, new / close desktop, leave desktop).

The launcher's own shortcut (`desktop.launcher`, `mod+k`) and the switcher's are
in other groups on purpose: they are not commands of themselves.

## Dock pinning

"Keep in dock" writes the desktop's global `shelfConfig.pinnedApps` (desktop shell core); the
row is withheld until that config has loaded rather than naming an action from
defaults.
