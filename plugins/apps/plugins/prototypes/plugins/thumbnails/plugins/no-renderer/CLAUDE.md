# no-renderer

The `ThumbnailRenderer` host service (`thumbnails/server`) for a host with no
browser to render with — the browser composition's worker. It answers
`unavailable` with a message, so `syncThumbnails` records a cache miss as the
card's `unavailable` state (a muted "Preview unavailable" marker over the
gallery's own cover) instead of `rendering`, which would promise a picture
nothing makes. Cache hits — PNGs a demo seed wrote into the `thumbnailCache`
root under their content fingerprint — are `ready` through the same sync, with
no branch of their own.

Base-excluded (`!apps.prototypes.thumbnails.no-renderer.**` in
`plugin-meta/composition/core/config.ts`), like every browser-host provider:
the desktop boots `thumbnails#machine`'s Chromium renderer instead.
