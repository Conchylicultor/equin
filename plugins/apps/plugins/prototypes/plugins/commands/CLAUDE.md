# commands

Declares the `./equin prototype` group — `new`, `list`, `options`, `log`,
`checkpoint`, `restore` (`cli/index.ts`). Design:
`research/2026-10-24-apps-prototype-list-hides-deleted.md`.

**Why a plugin of its own.** `list` needs two halves: the folders on disk
(`files`) and which of them the user deleted (`state`'s `prototype_state`, in
this checkout's instance DB). `files` cannot import `state` (`state` imports
`files`), and must not name `state`'s table. The group is one declaration and
cannot be split, so it sits here, above both.

**The bodies stay with their knowledge.** Five verbs are `files/cli`'s barrel
(`newPrototypeAction`, …), loaded behind a dynamic `import(…)` so the
declaration stays light (`cli:command-declarations-light`). `cli/list.ts`
composes the sixth: `readDeletedPrototypes(checkoutNamespace(root))`
(`state/cli`) → `printPrototypeList(deleted)` (`files/cli`), which leaves out the
deleted ones and counts them in a last line. When the DB cannot answer (down,
never built, older than the table), it lists everything and says why on stderr.
Every verb still needs no running backend.
