# covers

Song covers drawn from the REAL song (plan:
`research/2026-10-22-global-data-view-default-redesign.md`, decision 8).

- `core/` — pure renderers over a `Score` (never bytes; each source's route
  parses its own content and calls these):
  - `busiestWindow(score, bars = 4)` — the bar-aligned stretch with the most
    note starts (bar length = the first time signature, via `leadInBeats`),
    pitch range padded to whole octaves C..B, at least two.
  - `renderRollCover(score)` — 320×200 falling-notes SVG of that window.
  - `renderStaffCover(score)` — schematic grand staff of the opening bars.
  - `COVER_RENDER_VERSION` — bump when the renderers' bytes change.
- `server/` — `serveScoreCover({ version, current, contentHash, render })`.
- `data-dirs/` — `cache/sonata-covers` (host-global, reclaim safe).

## Decisions

- **Roll and staff covers are server-rendered SVG.** The piano-roll palette is
  fixed data in `look/core` (`SONATA_LOOK_STYLES`), not theme, so a server
  render loses nothing — and it is cached once for every surface and worktree.
  Chord-grid covers are the opposite case: they paint with the themable
  `--chord-N` tokens, so they render client-side (a `kind: "node"` cover) and
  are not here.
- **The default look, `immersive`.** A cached file cannot follow a per-user
  look switch; covers wear `SONATA_DEFAULT_LOOK` (lane, rules, track colours).
  The keyboard strip's ivory/ebony/seam are the keyboard primitive's
  `immersive` skin flattened (that palette is web-internal CSS today).
- **The staff cover is schematic**, because VexFlow needs a DOM. Notes are the
  song's own (diatonic step under the song key's spelling, ≤ 12 heads per
  staff, ≤ 2 ledger lines — a further note is drawn an octave closer); spacing
  is even, no clefs, rests or beams. Its palette is fixed here.
- **Cache keyed by content**: `sha256(contentHash|COVER_RENDER_VERSION).svg`,
  rendered on request (concurrent misses share one render via
  `packages/inflight`), written temp + rename. No job, no polling, no sweep —
  the dir is `reclaim: safe`.
- **URL versioned by the row's `sourcesChangedAt`**: `immutable` when the URL's
  version is current, `no-store` (still the current render) when stale. A render
  failure rejects → 500, reported; never a stand-in image.
