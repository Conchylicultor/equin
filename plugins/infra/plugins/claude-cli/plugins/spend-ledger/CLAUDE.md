# claude-cli/spend-ledger

The one Claude spend ledger: `claude_spend_hours (account_id, hour, source,
cost_usd)`, PK (account, hour, source) — what each Claude account spent per
UTC hour, at API prices, and what spent it.

- **`source`** (`core`: `SpendSource`, `conversationSpendSource`,
  `cliSpendSource`): `conv:<conversationId>` (the usage sync,
  `conversations/usage`), `cli:<sourceName>` (a one-shot call,
  `infra/claude-cli`'s recorder) or `unattributed` (the per-day history from
  before the ledger kept a source, migrated to 00:00 UTC of its day).
- **One write**: `spendLedgerUpsert(exec, rows)` — a builder (an arm of a
  `writeAtomically` group, or awaited in a transaction) that ADDS to the row
  (`cost_usd + excluded.cost_usd`). Each writer calls it inside the write that
  counted the cost, so a failed write files nothing and the next pass the same
  delta once.
- A leaf over `database` only, so it is portable: the usage server half (in
  the browser host) serves its reads without pulling in the SDK.

Design: [`research/2026-11-15-global-supervisors-spend-breakdown.md`](../../../../../../research/2026-11-15-global-supervisors-spend-breakdown.md).
