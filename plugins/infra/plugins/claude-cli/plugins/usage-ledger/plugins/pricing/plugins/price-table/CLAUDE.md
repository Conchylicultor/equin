# pricing/price-table

The Claude price table as a file and a fetch — what the dated price history
(the parent `pricing`: versions, rates, `claude_spend_hours_v`) is recorded
from. Split out of `pricing/server` so that barrel stays portable: the priced
view's readers run in the browser host too, and this half needs the file
system.

- `parseLiteLlmTable` — LiteLLM's `model_prices_and_context_window.json`,
  filtered to the Anthropic-relevant slice.
- `mergePriceTable` — unions, never deletes a key (a pruned model keeps the
  price we learned).
- `loadPriceTable` / `savePriceTable` — the persisted cache
  (`costUsageDir/price-table.json`, this plugin's `data-dirs`), atomic temp +
  rename; `fetchPriceTable` — upstream, through `safeFetch`.
- **The daily refresh** (`claude-cli.pricing.refresh`, `server/internal/
  refresh.ts`): main only (a fleet-wide cron, catch-up on a missed tick) —
  fetch, merge into the held table, save, `recordPriceVersion` (a new version
  effective now only when a rate moved), then `cost-unpriced-model` for every
  model the priced view leaves unpriced (`server/internal/unpriced.ts`, one
  report row per model; a zero-token `<synthetic>` is skipped). The boot
  warm-up (`claude-cli.pricing.record`, host scope) records the held table —
  or the vendored floor — as the first version on a database with none.
- **`costUsageDir`** (`cost-usage`, host state, never reclaimed) also holds
  the legacy year-sharded cost archive (`sessions-<YYYY>.json`), left in place
  read-only: nothing writes it any more; conversations/usage's history import
  reads it once into main's database. Do not delete it before main has
  recorded that import.
- `loadFallbackPriceTable` — the vendored `litellm-fallback.json` floor for a
  machine that never fetched; refresh it with
  `./equin run plugins/infra/plugins/claude-cli/plugins/usage-ledger/plugins/pricing/plugins/price-table/scripts/refresh-litellm-fallback.ts`.
