# claude-cli/usage-ledger

The one Claude usage ledger — **tokens, never dollars**. A cost is a read:
the `pricing` child's `claude_spend_hours_v` prices each row with the price
version in force at its hour. Design:
[`research/2026-11-16-global-unified-claude-cost.md`](../../../../../../research/2026-11-16-global-unified-claude-cost.md).

- **`claude_usage_hours`** — PK `(account_id, hour, source, model, speed, origin)`;
  the five token kinds (`input`, `output`, `cacheRead`, `cacheCreate5m`,
  `cacheCreate1h`) each split `_below` / `_above` the 200k tier (`core`:
  `DayBucket`, `UsageTokens`, `TOKEN_KINDS`, `TIER_THRESHOLD` — the bucket
  shape, its algebra in `core/internal/buckets.ts`), whole tokens (bigint).
  `model` is the string as observed. `account_id` is `UNKNOWN_ACCOUNT` for
  usage no pass could attribute.
- **One write**: `usageLedgerUpsert(exec, rows)` — a builder (an arm of a
  `writeAtomically` group, or awaited in a transaction) that ADDS each row's
  counts. A delta may be negative (a chain re-read takes tokens back); rows
  sharing a key are summed first; an hour off the hour or a non-whole count
  throws. A writer rounds each side of its delta, never the difference, so
  deltas telescope to the exact rounded total.
- **`origin`** (`core`: `UsageOrigin`): `counted` (a writer filing what it
  read: the scanners, the call recorder — `usageLedgerUpsert`) or `imported`
  (the one-shot history import, `usageLedgerImport`, conversations/usage).
  The scanners' take-backs — `usageLedgerRowsOf` (a source recounted whole)
  and `usageLedgerDropSources` (a session adopted by a conversation) — reach
  `counted` rows only: an imported row is usage of transcripts no scanner can
  read again, so nothing may take it back (a source row stays while an
  imported row names it). Readers sum both origins.
- **`claude_usage_sources`** `(source, project_dir, is_repo, title)` and
  `usageSourcesUpsert` — what a reader needs about a source without reading
  the transcript corpus; a known fact is never replaced by an unknown one.
- **`source`** (`core`: `SpendSource`): `conv:<conversationId>` (the usage
  sync, `conversations/usage`), `cli:<sourceName>` (a one-shot call,
  `infra/claude-cli`'s recorder), `session:<claudeSessionId>` (a session equin
  did not launch).
- Writers call `pricing`'s `ensureModelRates` after their write, so a model
  first seen is priced at once.

**The one system.** Every Claude cost surface reads this ledger through the
priced view — the Cost column and per-conversation cost, account spend and
supervisors spend (conversations/usage, tasks/supervisor-roles/spend), Stats →
Cost (stats/cost's rollups). The writers: the transcript scanner
(conversations/usage machine — `conv:` and `session:`, every transcript on the
host), the CLI call recorder (`cli:`, from the result's `modelUsage`) and the
one-shot history import (`imported`: each conversation's pre-ledger count and
the legacy cost archive's deleted transcripts). **Permanence is main's
database**: no row is deleted when its transcript vanishes, and the database
backup covers it. The legacy dollar ledger (`claude_spend_hours`) is gone; its
`unattributed` dollars live on as conversations/usage's
`claude_account_spend_carryover`.

- A leaf over `database` only, so it is portable: the usage server half (in
  the browser host) serves its reads without pulling in the SDK.
