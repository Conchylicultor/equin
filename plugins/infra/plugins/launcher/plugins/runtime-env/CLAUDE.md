# runtime-env

What environment the runtime tree (the gateway and everything it starts)
starts from — a declared allowlist, never the starter's whole environment — and
the runtime's `PATH`, with mise's shims first. The design is in the header of
`core/internal/runtime-env.ts`.

A core-only leaf of `launcher` rather than part of `launcher/core` because its
importers are mostly not launchers: the python and rust dependency runners, the
toolchain pin, the agent session environment. A composition's closure is per
plugin, so importing these helpers from `launcher` brought the launcher's
release boot (which writes the worktree spec) into every bundle that runs a
python tool — Sonata's audio analysis among them.
