# launcher/gateway-port

This account's gateway port: the one value every browser address, OAuth
redirect URI, bookmark and the menu-bar helper depend on. Design:
[`research/2026-11-17-global-gateway-port-v2.md`](../../../../../../research/2026-11-17-global-gateway-port-v2.md).

- **8700 by default**: the first free port of 8700–8709
  (`GATEWAY_PORT_RANGE`, `infra/namespace/core`), chosen once and kept by the
  account, so separate macOS accounts run equin side by side. 9000 (the old
  port) clashed with PHP-FPM, MinIO, Portainer, ClickHouse and SonarQube.
- **Recorded** in `~/.equin/state/gateway-port/port.json`,
  `{"port": 8700, "legacy": 9000 | null}` (`GatewayPortRecordSchema`), **only
  once a gateway answers on the port**: `./equin start`
  (`writeGatewayPortRecord` after `awaitGatewayReady`), or main's follow
  moving an install off 9000 (`gateway-drift`'s switch helper). Choosing
  (`chooseGatewayPort`: binds both loopbacks, names each taken port's holder)
  writes nothing, so a rolled-back move leaves no file naming a port nothing
  listens on.
- **Moved by hand** only with `./equin start --port <n>`. A recorded port held
  by something else is a loud refusal naming the holder, never a silent move.

## Who reads what

Each runtime reads the authority that is right for it — there is no "the
port" constant, and `namespaceUrl` / `namespaceHost` / `contentUrl` take the
port as a required argument.

| Process | Reader | Source |
|---|---|---|
| A process a gateway started (backend, central, deploy run) | `servedGatewayPort()` (core) | `EQUIN_GATEWAY_PORT`, which the gateway sets from its own `-listen` (gateway/env.go) — so a backend always dials the gateway it runs under, a deployed box included. Unset only under a gateway older than the variable, which always listened on 9000. |
| CLI, scripts, checks | `gatewayPortSync()` / `gatewayOriginSync()` (data-dirs) | the env above if set, else the port file, else 9000 (an install that has not moved yet) |
| A page | `usePagePort()` (web), `pagePort(location)` (core) | the page's own `location.port` |
| The menu-bar helper (Rust) | `gateway::port()` | the file named by `EQUIN_GATEWAY_PORT_FILE`, which the tray's job carries (`menu-bar/login-services`) |
| Shell (`install.sh`) | `./equin url` | main's address on this account's port |
| `./equin start` | `probeGateway(port)` | `GET /gateway/identity`: nothing, this account's gateway, another account's equin, or something else |

## The legacy port

An account that moved off 9000 records `legacy: 9000`. Its gateway gets
`-legacy-listen loopback:9000` and keeps answering there: API, WebSocket,
`/gateway/*` and MCP are served as on the main port (running agent sessions,
open tabs, worktree builds on old branches), and a top-level document
navigation is redirected (`308`) to the same address on the new port
(bookmarks). `gateway/CLAUDE.md` § The port has the rule and its exemptions. The flag is dropped by a later commit, so the
push is what triggers the one restart it costs, never a clock.

## Enforcement

`gateway-port:no-port-literal` (`check/`): no legacy or range port after a
loopback or namespace host in code, comments or docs, and no bare port
number in Go, Rust or shell — test code, JSON data and research notes aside.
The menu-bar helper's `LEGACY_PORT` is its one declared exemption.
