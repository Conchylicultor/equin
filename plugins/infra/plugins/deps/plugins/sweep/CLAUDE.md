# sweep

The daily `deps.sweep` job (main-only by its schedule): lists this repo's
checkouts (`git worktree list`), keeps the ones still in use — main's own,
and every agent checkout whose attempt is retained (`attempts_v.retained`) or
whose row main does not hold — and hands them to the engine's
`sweepUnusedDeps`, which removes every installed identity none of them
declares that is not held and sat unused for 14 days. A finished attempt's
checkout keeps nothing: what it last used is protected by the idle window, and
a resume installs anything missing on demand. (Asking all ~450 checkouts on
disk, most finished, for every declaration made the sweep an hour of git on
2026-11-20.)

It is a sub-plugin rather than part of `infra/deps` so the engine carries no
edge to `infra/worktree`, an agent-runtime taproot. An app that runs an
on-demand dependency but must stay free of the agent runtime (Sonata, through
`infra/audio-analysis`) then closes over the engine only.
