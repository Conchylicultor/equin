# connection-row

The health report's **Connection row**, split from `infra/health` so a
composition can leave the row out without losing the restart toast, the wedge
watchdog or `/api/health` (the showcase film's composition does: a main restart
flickers it, which is the machine's news, never the film's).

`connectionHealth` (`web/internal/connection-health.ts`, bun-tested) folds the
two notification sockets — this worktree's server and central — into one
status: both open is ok, any closed is critical and names which, and any still
(re)connecting is attention with `transitioning` set so the dot pulses. An open
socket whose server's heartbeat reports a change undelivered for ≥
`PUSH_STALL_MS` (`infra/health`'s, shared with the wedge watchdog) is critical
too — "live updates stuck". Closed outranks stuck; stuck outranks
(re)connecting. One resource whose own push is stuck that long while the rest
flow is attention, naming the resources — the least of the four.
