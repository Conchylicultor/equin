# shed

The duress **shed engine**: `createShedBuffer<T>({ kind, cascadeKeyOf, replay,
onFlushSummary? })`, the one way an observability choke point (trace capture,
slow-op recording, report filing, the latency ledger) sheds its durable writes
during a duress episode without losing the accounting. The full contract —
first-N per cascade key, the bounds, the lazy flush — is in the parent
[`duress`](../../CLAUDE.md) CLAUDE.md ("The shed engine").

A sub-plugin of its own so the parent's `server/` barrel is register-only and
`portable: true`: the engine reads the latch (`plugins/latch`, the host's
filesystem), which no browser host has, while the duress config it is tuned by
must be registered in every host whose page can show it. The engine reads
that config through the parent's `readDuressConfig` (`duress/server`): a
server import is what puts the parent — and its registration — in every
composition that ships the engine (a `core` import draws no closure edge).
Consumers import
`@plugins/infra/plugins/host/plugins/duress/plugins/shed/server`.
