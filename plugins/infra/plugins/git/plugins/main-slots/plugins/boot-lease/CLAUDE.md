# boot-lease

A main slot's lease as files, and the hold an entry point takes on it BEFORE
it loads code from the slot. See the parent `main-slots` for what a slot is.

- **The layout** (`core/internal/layout.ts`), all in the slot's git admin dir:
  the lock file (`tree.lock` — the flock every main-slots lease takes), the
  holder records beside it (`leases/<pid>.<n>.json`, `{pid, kind, mode,
  acquiredAt, label}`; a record without `label` — the guard bootstrap's copy —
  reads as `null`), the main-slot stamp, main's `main-slot-served` marker,
  the unserved stamp (`main-slot-unserved`, `{at, reportAfterMs}`), the handoff
  mark (`main-slot-handed`), the drain records (`drain-log/`), and the closed
  set of holder kinds (`SLOT_HOLDER_KINDS`; `drainsByDesign` names the kind
  that outlives its slot's switch on purpose, `build-relay`). One spelling for
  main-slots' own leases, this hold, and the guard bootstrap's copy
  (`tooling/guards/bin/bootstrap.ts`, which may import nothing from the repo;
  its test holds the copy to these values).
- **`drainRecordFor`** (pure): the drain record a release owes, or `null` —
  no stamp (the slot still serves), a `build-relay`, or within the threshold.
  `noteLeaseReleaseSync` (`core/internal/drain-sync.ts`) writes it with plain
  `fs`, on the release paths that load nothing else; `releaseRecordSync` is a
  record's whole end (note, then unlink) — also a lifetime lease's, from its
  process's exit handler.
- **`holdSlotLeaseSync(root, kind, label)`**: `not-a-slot` unless `root` is a
  stamped main slot; else one `open(…, O_SHLOCK)` of the lock file (blocking
  the thread while a build holds the slot exclusively — macOS only, the only
  host slots exist on) and a holder record, ended on `release()` or by an
  exit handler (with its drain note). Light by construction (node builtins
  plus a few leaf barrels), because its callers take it before loading the
  code it protects:
  - the CLI bootstrap (`framework/cli/bin/index.ts`) — every `./equin` run
    from a slot holds it for life, kind `exec-child` (labelled by its verb — `run <script>` for a
    `./equin run` — or a supervised child's job name) or `build-relay` (a `./equin build`), except
    in the slot handed to a build (`EQUIN_BUILD_SLOT`);
  - the agent host (`conversations/runtime-sdk/bin/agent-host.ts`), kind
    `agent-boot`, released by `bin/agent.ts` once its static imports are in.
