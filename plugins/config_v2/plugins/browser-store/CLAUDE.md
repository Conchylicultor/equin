# browser-store

The config host services (`config_v2/server`'s `ConfigStore` and
`ConfigGitLayer`) of a host without the computer — the browser worker host:

- `ConfigStore` is `createMemoryConfigStore()`: the user layer lives as long as
  the worker (a reload is the committed state again).
- `ConfigGitLayer` is not delivered yet: `hasScope` throws, naming the storePath
  and the step that delivers `@composition-config-layer` to the host build. The
  worker's registry holds no descriptor today, so nothing calls it.

The desktop provides both from `config_v2#machine`; this plugin is excluded
from every desktop app by the composition config's base-exclusions row (two
providers of one service fail boot).
