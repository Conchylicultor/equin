# browser-store

The user config layer (`config_v2/server`'s `ConfigStore`) of a host without
the computer — the browser worker host: `createMemoryConfigStore` (core), which
lives as long as the worker (a reload is the committed state again).

It starts as a fresh user's: the first time the registry touches a storePath,
the store propagates that path's committed document into itself
(`propagatedFrom: ConfigGitLayer.get().document`, through
`propagateGitLayerDocument` — the function the desktop build propagates
`config/` into a file store with). The committed layer is another provider's:
`config_v2/plugins/bundled-layer` in a browser host.

The desktop provides the store from `config_v2#machine`; this plugin is
excluded from every desktop app by the composition config's base-exclusions
row (two providers of one service fail boot).
