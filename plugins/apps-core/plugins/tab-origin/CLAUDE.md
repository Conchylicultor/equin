# tab-origin

Says which browser tab raised something — a notification, a report — relative
to the page reading it. Producers stamp `clientId` (`getTabId()`) and the page
URL; `useTabOrigin(stamp)` reads them as this tab, or another one named by the
app its page belonged to (path → app through `matchAppForPath`, past a surface
prefix such as `/desktop`) and whether that tab is still open
(`useTabPresence`, tab-id's shared Web Lock per tab id, read once on mount).
`tabOriginLabel` renders it: "this tab", "another Places tab", "closed Menu
bar tab". Hidden pages count as tabs: the menu-bar panel and installed app
windows are pages of the origin like any browser tab.
