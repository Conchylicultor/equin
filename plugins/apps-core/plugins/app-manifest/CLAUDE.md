# app-manifest

Makes every listed app installable as its own OS app (Chrome / Edge "Install",
Safari "Add to Dock"): one web-app manifest per app, its icon as PNGs, and the
head tags linking them from the app's pages.

- **The app set** is `declaredApps` (`apps-core/server`), generated at build
  from the `Apps.App` contributions — each app's whole `AppRef` (id, name, base
  path, `icon`, `iconColor`) and its launch kind. Every listed app installs
  (`installableApp`) — a surface-mode app (the desktop) too: its base path is
  the route prefix of every page it shows (`/desktop/agents/c/x`, see
  `apps-core`), so `/desktop` is its scope. An unlisted app's manifest and
  icons are a 404.
- **`server/` (portable)** — `GET /api/apps/:appId/manifest.webmanifest`
  (`getAppManifest`, `appManifestFor`): `id`, `start_url` and `scope` are the
  app's base path (distinct per app, so no two scopes overlap; the scope is the
  bare base path because `start_url` must lie inside it), `display:
  standalone`, the tile colour as `theme_color` / `background_color`, and the
  192 / 512 icon PNGs. A `DocumentHead.Fragment` keyed per base path adds
  `<link rel="manifest">`, `<meta name="theme-color">` and
  `<link rel="apple-touch-icon">` to that app's pages.
- **`machine/`** — `GET /api/apps/:appId/icon/:file` (`getAppIconPng`,
  `needsMachine`; `:file` is `<size>.png`, sizes `APP_ICON_SIZES` = 192, 512,
  1024): `appIconToSvg` (`app-icon/core`) over the glyph `symbolBody`
  (`ui/icons/server`) reads from the installed icon sets, on `appTileFill` (the
  same colour the rail's tile paints), rasterized with resvg like the release
  CLI, memoized per app and size for the process's life (its inputs only change
  with a build, which restarts it).
- **Installed = the app's own document.** An installed app's window runs in
  `display-mode: standalone`, which the app treats like any browser tab: not
  embedded (`primitives/embed`), so it keeps its tab set across a reload, and
  not chromeless, so it boots in solo mode with the floating global action bar
  (the app can be improved while in use).
- Chrome treats `*.localhost` as a secure context, so install works on
  `http://<namespace>.localhost:9000`.
