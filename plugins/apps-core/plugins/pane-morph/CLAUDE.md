# pane-morph

A pane's cross-app Expand ("Open in <App>") runs as a **view transition**: the
pane grows from its box into its place in the app that replaces this one.
Design and prototype: `research/2026-10-29-apps-core-pane-morph.md`
(prototype `proto-1793274267-ojlxu9`).

- **The seam.** The pane primitive owns which box was expanded
  (`useMorphFromPane`, `primitives/pane/web/morph-sink.ts`); this plugin installs
  the implementation into `paneMorphSink` at `Core.Root`. A composition
  without it navigates plainly.
- **What is matched**, by `view-transition-name`, for one morph only (so
  several visible tabs never carry duplicate names):
  - `pane-morph` — the expanded box ↔ the box of the new route's **leaf** pane
    (not the same pane id: a peeked file lands on Files' folder pane);
  - `pane-morph-title` — each box's `[data-part="pane.title"]`;
  - `pane-morph-sidebar` — each app's `[data-slot="sidebar-container"]`.
  Both sides are found inside the tab's `[data-tab-id]` element — the one
  element that outlives the app swap.
- **Only persistent elements are named.** Removing or replacing a named
  element mid-flight aborts the transition, so a loading pane must swap its
  content INSIDE its box (it does: `PaneBox` stays, the resolve guard swaps).
- **The navigation commits inside the transition** (`flushSync`), so the new
  app is the live new state and the morph starts on the next frame — nothing
  waits for data; a pane still loading morphs into its loading state.
- **Plain navigation** without `document.startViewTransition`, under
  `prefers-reduced-motion`, while a morph runs, or outside a tab.
- **Look** (`web/internal/morph.css`, all scoped to `html[data-pane-morph]`):
  440 ms; snapshots cropped top-left, never stretched; the old pane picture
  fades in the first 40 %; the old app recedes (scale .96, blur, fade), the
  new one rises.

## Plugin reference

- Description: The pane → app morph: a pane's cross-app Expand ("Open in <App>") runs as a view transition in which the pane grows from its box into the leaf pane of the app that replaces this one — the old app receding, the new one rising, the two apps' sidebars cross-fading in place and the header title gliding between headers, snapshots cropped and never stretched. Installed into the pane primitive's paneMorphSink at Core.Root; falls back to the plain navigation without View Transitions, under reduced motion or mid-morph.
