# tree-disclosure

## Default: `column`

The base pick is `column` (`core/region.ts` `defaultVariant`, and so the
generated origin): a chevron box (`w-tree-chevron`, density `treeChevronW`)
ahead of the icon, holding a chevron only on a row with children — 40% at rest,
full on row hover or keyboard focus, a focus ring for keyboard focus only (a
mouse click leaves none) — and empty space on a leaf, so every icon sits on one
rail. The component is the tree's own `TreeColumnDisclosure` (it is also the
tree's fallback with no `Tree.Disclosure` contributed, so a composition without
this plugin draws the same rows); the `column` variant contributes it. It
renders two cells of the row, spaced by the row's `gap-tree-row`, which is what
the density defaults assume: indent = chevron box + row gap (a child's chevron
under its parent's icon), guide at half the chevron box (under its parent's
chevron).

`merged` and `dimmed-leaf` keep their one 20px icon box; it starts where the
chevron box would, so the default guide lands on the parent icon's centre.
Pages and the file explorer pin `merged` under
`config/ui/tree-disclosure/@app/<id>/` and set their own `treeIndent` in their
themes, so the new default leaves them unchanged. Changing the default rewrites
the origin's `@hash`: restamp those overrides.
