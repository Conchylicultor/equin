# logo

The equin logo, from one source. Its geometry lives in `core/` as data
(`LOGO`: the outer arc, the lift, each master's bowls and line width, the
small-master breakpoint, the gradient); nothing else in the repo spells a path.

- **In the app** — draw `<Logo className tone />` (`web/`). It holds both
  masters and shows the small one below `LOGO.smallBelowPx` by a container
  query on its own box, so callers only size it. `tone="current"` for quiet
  chrome (the tab bar's corner mark).
- **Outside the app** — what cannot import TS reads generated files: the page's
  favicons (`web-core/web/public/icon*.svg`, `icon_{16,32,512}…png`, linked from
  `web-core/web/index.html`) and the native helper's icons
  (`menu-bar/rust/icons/{app,tray,tray-attention}.svg`, rasterized by its
  `build.rs`). `LOGO_FILES` lists them, as data.

## Changing the logo

1. Edit `core/internal/geometry.ts` (or a file's options in `core/internal/files.ts`).
2. `./equin run plugins/ui/plugins/logo/scripts/render.ts` rewrites every file.
3. `./equin build`.

`logo:files-in-sync` fails until step 2 is done: each SVG must equal what
`logoSvg` renders now, and each PNG must carry (a `tEXt` stamp) the digest of
the SVG and size it was rendered from — compared without re-rasterizing, so
the check does not depend on the rasterizer's version.
