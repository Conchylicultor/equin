# bundled-sprites

The `SpriteDrawer` of a browser host (the in-browser demo's worker): the
never-resident sprites a scope's icons want, drawn from sets bundled with the
worker — the vendored Seti file-type set (every glyph, so no manifest is
needed) and `@iconify-json/lucide` (every name `LUCIDE_MAP` draws), each a
lazy chunk loaded on its first read. Built by the same portable assembly the
desktop's drawer uses (`sprites/server`'s `buildSetiSprite` /
`buildLucideSprites`), so the ids and drawings match the page's.

The Material styles and the brands are the page's resident sprites; a read of
one here is refused `not-drawn-here`. A host provider: never in a composition,
never booted by the desktop.
