# color-ref

`ColorTokenRef` — a reference to a DECLARED colour token: its CSS var
(`"--categorical-3"`, `"--success"`), drawn as `var(<ref>)`. A tint naming a
colour no palette declares is a tsc error, and a theme that re-colours the token
re-colours every tint that names it. Carried by `FieldOption.tint` /
`GroupBucket.tint` (data-view), `LiveFieldOption.tint` (network/live) and
Sonata's source tints.

- **Generated, zero imports.** `core/color-token-ref.generated.ts` is a plain
  string-literal union written by codegen
  (`framework/tooling/codegen/core/color-token-ref-gen.ts`) from the real token
  group descriptors. Deriving it with `TokenVarOf<typeof group>` would import
  theme-engine (→ config_v2 → network/live), a cycle for its lowest consumers.
- **Closed palette list** — `COLOR_TOKEN_REF_GROUPS` in that generator (the app
  palette, categorical, chart, chord-palette). Adding one widens every tint.
- **Regenerated** by `./equin build` / `./equin regen-generated`; the
  `color-token-ref-in-sync` check fails on drift.
- Import it with `import type` only: a type-only edge keeps the generated file
  unreachable at module-load, so no barrel freezes a stale copy.
