# type-scale

The type-scale token group: every typographic size, line height and weight
in the app, and nothing else declares one. Its keys are the **closed role
ladder** — `TYPE_ROLES` in the text plugin's `core/roles.ts` — derived by
`roleTokenKeys()`, plus a short non-role list: `fontScale`, the inherited base
(`fontSizeBase` / `lineHeightBase`), `measureReading`, the 2xs/3xs sub-scale and
the four shared weights.

- **A theme sets roles**, never component tokens: `fontSizeLabel`,
  `lineHeightBody`, `fontSizeGroup` (a list's group headings),
  `fontWeightControl`, `fontSizeTagCompact`, … There is no
  `fontSizeChip` or `sidebarLabelSize` to set — a component picks a role
  (`<Text variant>` / `text-<role>`) and inherits whatever the theme gives it.
- **Role sizes and line heights are literal lengths**, never `var()` chains (a
  chain freezes inside a sub-theme that only emits the keys it names) and never
  unitless (`--font-scale` multiplies them). Only the `*Strong` weights chain to
  their role's weight. `core/group.test.ts` pins this.
- **`fontScale`** (`--font-scale`, default `1`) multiplies every role, rung,
  sub-scale size and the inherited base, at the element (in ui-kit's `app.css`
  utilities). Weights, spacing and the reading measure do not scale. See the
  text plugin's CLAUDE.md for the full model and `typeVar()`.
- **`fontSizeBase` is `1rem`, not `1em`**: every pane is a nested `<Theme>`
  scope, so an em base would compound the scale per nesting level.

Enforcement lives here: `lint/no-arbitrary-font-size` bans `text-[Npx]` /
`text-[Nrem]` (only the sub-scale's 10px / 11px auto-fix; a 12px size is a
role, chosen by a person), and the `type-scale:closed-role-ladder` check
(`check/index.ts`) fails when this group's keys differ from the ladder's, when
another token group declares a size / line height / weight, when an `app.css`
`@utility` sets type metrics without being a derived role utility (or skips
`--font-scale`), when the `no-adhoc-typography` message stops naming a `<Text>`
variant, or when TS outside the text and type-scale plugins reads a raw
`var(--font-size-*)` / `var(--line-height-*)`. Adding a non-role key means
editing that check's `NON_ROLE_KEYS` with a reason; adding a role means adding
it to `TYPE_ROLES`, from which its tokens, utilities and `<Text>` variant all
follow.
