# overlay

How floating things behave and look beyond their material (`material`),
corners (`shape`) and shadow tiers (`shadow`). Every default is the look the
app had before this group existed, so a theme that leaves it out changes
nothing.

**Panel entry** — read by `OverlayPanel` (`data-open:overlay-enter` in ui-kit's
`app.css`), so every popover, menu, select, dialog and hover card:

- `overlayEnterDuration` (default `0ms` — panels appear at once),
  `overlayEnterEasing` (`ease-out`), `overlayEnterTranslate` (a CSS `translate`
  value the panel starts at, `0px 0px`), `overlayEnterScale` (`1`). The panel
  also fades in from transparent. Off under `prefers-reduced-motion: reduce`.
  There is no exit animation.

**Tooltip chrome** — read by ui-kit's `TooltipContent` (the one-line label every
control's `tooltip` prop draws; not the hover card, which is an `OverlayPanel`):

- `tooltipFill` / `tooltipForeground` (`bg-tooltip` / `text-tooltip-foreground`,
  default the popover's) — an inverted tooltip sets the foreground as the fill.
- `tooltipBorder` (`ring-tooltip-border`, default the foreground at 10%).
- `tooltipRadius` (`rounded-tooltip`, default the `rounded-md` step),
  `tooltipPadX` / `tooltipPadY` (`p-tooltip`, default `md` / `xs`),
  `tooltipShadow` (`shadow-tooltip`, default `--shadow-md`).
- `tooltipOffset` (`tooltip-offset`, default `4px`) — a margin on the popup's
  side facing its trigger, so placement and flipping include it.
- `tooltipArrowSize` (`tooltip-arrow`, default `0.625rem`; `0px` = no arrow).

- `tooltipRole` (default `caption`) — which type ROLE its words are set in, a
  value naming one of the closed ladder's roles (`TYPE_ROLES`), never a size;
  `tooltipEmphasis` (`regular` | `strong`) — the role's strong weight, for the
  roles that have one (`control`, `tag`). `TooltipContent` applies the role's
  own utility through one CSS style query per role (`TOOLTIP_ROLE_CLASS`,
  typed `Record<TypeRole, …>` so it covers the ladder), so sizes and weights
  stay the type-scale group's. Without style-query support a browser draws
  `caption`.

A popover's own padding is not here: it is density's `popoverPad`, beside the
popover width roles (the `panel` padding role).
