# density

## Gallery, cover and sticky-fade geometry

- `galleryCardMin` / `galleryCardMinCompact` (`--gallery-card-min`,
  `--gallery-card-min-compact`; 13.75rem / 10.5rem) — the DataView gallery
  card's minimum width, read as `<Grid minCellWidth="var(--gallery-card-min)">`.
- `galleryGapX` / `galleryGapY` (`--gallery-gap-x/-y`, the `lg` / `xl` steps) —
  utilities `gap-x-gallery` / `gap-y-gallery`.
- `coverThumbW` / `coverThumbH` (`--cover-thumb-w/-h`, 3.25rem × 2.125rem) — a
  list row's cover thumbnail, utility `size-cover-thumb`.
- `stickyFadeTail` (`--sticky-fade-tail`, 1.75rem) — how far `Sticky
  mask="fade"`'s gradient tail hangs past its band.

## Pane content inset

- `contentInset` (`--content-inset`, default `initial` = unset) — the one
  inline inset a `PaneChrome inset="content"` pane gives a DataView's toolbar
  and its content (its header keeps `chromePanePad*`): the pane publishes
  `--pane-inset: var(--content-inset)` (a container, so `cqi` is pane-relative)
  and `rail-follow` floors at it
  (`var(--rail-owed-start, var(--rail-start, var(--pane-inset, var(--chrome-pad-x))))`).
  Unset, `--pane-inset` is invalid and every rail falls back to the chrome pad
  exactly as before.
