# autonomous-run

The autonomous-run workflow (Autonomous tasks track, Mode step;
`research/2026-10-29-tasks-autonomous-run-mode.md`). The only
autonomous-specific code — a composition of the building blocks:

- **Entry point:** the Autonomous launch option (`TaskLaunch.Option`, draft
  only), shown on every new-task composer: Interactive (unset, the pill rests
  as its icon) or Autonomous. No push variants: how a run pushes is the
  user's brief or preprompt.
- **Mandate:** its server apply states `autonomousMandate()`
  (`tasks/mandate-presets`) on the task it files. Everything else follows from
  the grants: agents file now / after / manual (`tasks.file`), report
  (`report.required` + stop gate), watch what they file (`watch.children`),
  compact themselves (`context.compact`); the agent on the root watches the
  whole tree (`watch.tree`, taken over by each new conversation there).
- **No supervisor prompt:** the user writes the brief (and picks a preprompt).
  Not inherited: filed tasks are covered by the root's mandate already.
