# tab-evidence

What a browser tab's own thread ran over a window, as **evidence** a report
carries — never its identity: the JS stacks its rolling JS Self-Profiling trace
sampled (`StallStacks`) and its JS heap around the window (`StallMemory`), plus
`stacksSection` / `memorySection`, the markdown a task renders them as.

The profiler and heap watch that produce them live in the parent
(`main-thread-stall/web/internal/stall-profiler.ts`, `heap-watch.ts`). This is
a leaf (zod only) so `debug/slow-ops` — whose sink main-thread-stall feeds —
can carry them on a `main-thread` slow-op's report without a cycle.

Carried by: a `main-thread-stall` report (`stacks`, `memory`), a
`slow-interaction` report (`stacks`), and a `slow-op` report of a 1–5 s long
frame (`evidence: TabEvidence`).
