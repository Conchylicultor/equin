# panel-overflow

The report kind for **a popover control panel whose showing page is wider than
the panel** — the measured backstop behind control-panel's width-from-content
model (see "The content declares its width" in
[`plugins/primitives/plugins/css/plugins/control-panel/CLAUDE.md`](../../../primitives/plugins/css/plugins/control-panel/CLAUDE.md)).

A panel's width is the bucket its content declares (`data-cp-needs`). A page
whose content needs more than it declares spills past the panel's edge; the
control-panel overflow guard measures that and emits a `PanelOverflowFault`
into `panelOverflowReportSink`. This plugin **drains that sink**:
`PanelOverflowCollector` (mounted via `Core.Root`) maps each fault onto
`report({ kind: "panel-overflow", … })`. The dependency runs one way — a
primitive never imports `reports` — the same inversion viewport-escape uses.

Fingerprint: panel label + page title. That pair is the defect (one page
missing one declaration); widths and the offender's classes vary with the
theme, data and viewport, and are excluded.
