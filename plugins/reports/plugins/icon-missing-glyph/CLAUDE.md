# icon-missing-glyph

The report kind for **an icon whose held sprite has no symbol for it**: the
sprites ship exactly the build's icon manifest, so the manifest missed a name
the code draws (see "The rules" in
[`plugins/ui/plugins/icons/CLAUDE.md`](../../../ui/plugins/icons/CLAUDE.md)).
`<Icon>` draws the missing-glyph marker (a crossed-out dashed square) instead of
an empty box, and emits an `IconMissingGlyph` into
`iconMissingGlyphReportSink`, once per (sprite, symbol id) per page. This plugin
**drains that sink**: `collectIconMissingGlyph` (a `ReportSinks.Collector` keyed by
`ui.icons`) maps
each onto `report({ kind: "icon-missing-glyph", … })`. The dependency runs one
way — the icons leaf never imports `reports`.

Fingerprint: sprite + symbol id — one symbol one sprite lacks is the defect.

Its static twin is `icons:manifest-covers-uses`, which catches the same defect
before it ships, from an oracle independent of the manifest generator.
