# collectors

The browser's sink collectors, opted into as one set. Owns
`ReportSinks.Collector` and `SinkCollectors`, the host that attaches every
collector it can see (`Core.Root`, `scope: "each"`: at the page root and inside
every `PluginScope`, so a collector the page holds only on demand — the
website's live demo — drains its sink once the scope loads it).

A collector is a companion of this plugin keyed by its producer
(`companions: { key: "from", space: "plugin" }`): it ships where this plugin
AND the plugin declaring the drained sink both ship. The `reporters` pack names
this plugin instead of each collector, so a composition gets exactly the
collectors whose producers it already holds and never a producer for its
collector's sake. How to write one, and the lint rules holding it: see
[`primitives/report-sink`](../../../primitives/plugins/report-sink/CLAUDE.md).
