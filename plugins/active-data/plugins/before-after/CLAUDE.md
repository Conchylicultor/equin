# before-after (chip)

The `ba-…` id chip of a before / after pair (`conversations/before-after`),
following `active-data/prototype`: `BEFORE_AFTER_CHIP_SURFACES` (`core/`, read
by both halves) — transcript and document.

- **Server** — `idChipServer({ kind: baIdKind, live, surfaces, resolve })`: the
  pair's title for the id registry and model-read text; `live` follows the
  pair's row (`beforeAfterPairsServed`) by id.
- **Web** — `idChip({ presenter: { kind, icon, useReferent, usePane } })`:
  `useReferent` = `rowReferent(useLive(beforeAfterPairs, { id }), (r) => r.title)`,
  `usePane` = the Before / after pane on the pair (`beforeAfterPane`). No hover
  preview: the generic id chip has no hover slot.

## Plugin reference

- Description: Renders raw `ba-<id>` strings inline as clickable chips (the generic id chip: the pair's title) that open the pair in the Before / after pane beside the text, and presents the before / after id kind to the id registry. Models emit the bare id an agent was handed by register_before_after. The before / after pair id chip's server half (idChipServer): resolves a `ba-<id>` to its pair's title for the id registry and for model-read text, and registers the page-editor inline token so a page block holding the chip stays agent-readable.
