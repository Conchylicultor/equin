# show-me

`<show-me path="…" element="…">the Share button</show-me>` points the user at
an element of the live page. `path` / `element` are the two fields a
`<ui-context>` token names an element by — copy them from an outline entry
(`collectOutline` / `formatOutline`, `primitives/ui-context`): `path` is the
entry's lineage path (its group lines joined by ` > `), `element` its
descriptor (`button — Share`, without a `×N`). No hand-written anchor labels.

- **A target chip**, inline wherever it is written (a multi-line body draws
  the same chip). The quoted `path` holds ` > `; active-data's open-tag
  grammar (`TAG_ATTRS_SOURCE`) allows `>` inside quoted values for this.
- **Click → resolve now → highlight.** `resolveUiContext` runs at the click
  (the page may have changed since the agent read it): `found` / `ambiguous`
  (the first match) → `pointAt(() => el, { label })` from `hints/web` —
  a pulsing ring (and the label as caption when the element shows no text
  of its own — an icon-only button), non-modal: it fades after a few
  seconds or at the user's next click, which goes through to the page.
  `gone` → a "Not on this page" toast, and the chip then wears the
  `location-disabled` icon and says so in its tooltip; a later click looks
  again. Every miss is logged to the browser channel `show-me`
  (`~/.singularity/worktrees/<wt>/logs/show-me.jsonl`): the path and element
  asked for, the URL, and `resolveUiContext`'s `near` — the same element
  elsewhere (its path, shown or not) and the controls shown where the path
  points. Read it before trying to reproduce a "Not on this page". A tag with no `element` draws a disabled-looking chip whose click
  throws. `pointAt` throws while a tour runs — left loud.
- **One step.** Next through the message's other show-me tags is not offered:
  an inline renderer is handed its tag only, not the message around it.
- Works on every surface that renders active-data (the transcript,
  `AgentThread`). Contribution segments of a path exist only where
  `element-picker`'s middleware is in the composition.
