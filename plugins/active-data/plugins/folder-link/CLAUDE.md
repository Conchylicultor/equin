# folder-link

A backticked folder path in agent prose — `` `~/Downloads/showcase/` ``,
`` `/tmp/out` ``, `` `plugins/apps/` `` — becomes a chip that browses the folder
in a side pane (`apps/file-explorer/folder-peek`: the whole Files browser, Up
included, with Expand to Files).

**Never a file path.** The active-data chain runs before the file-path inline
code handler (`conversation-view/markdown-extensions`), and a candidate that
matches and then declines renders the plain terminal — so `FOLDER_PATH_RE`
must not full-match anything `FILE_PATH_RE` links as a file: a folder path ends
in `/` or in a dotless segment that is not a well-known extensionless file name.
`pattern.test.ts` pins the disjointness.

**Claimed only when it is a folder.** `useFolderClaim` stats the path
(`host-fs.stat`) and claims only an entry of kind `dir`, its value the resolved
absolute path. A relative path is relative to the host's
`FileLinksWorkspaceProvider` root; with none it declines. Every refusal is a
settled decline, never pending (a pending claim stops the chain).
