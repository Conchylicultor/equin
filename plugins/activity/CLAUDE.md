# activity

Recent activity: tasks, conversations and pages in ONE list, newest activity
first — the reference **Meta-DataView over entities** (data-view's CLAUDE.md,
*Meta-DataView*). Design:
[`research/2026-10-17-global-fields-declared-once-phase4-entity-meta-dataview.md`](../../research/2026-10-17-global-fields-declared-once-phase4-entity-meta-dataview.md).

## Shape

- `activity` (core) is a union collection (`liveCollection({ arms: {
  discriminator: "type" } })`): base fields `title`, `type`, `updatedAt`
  ("Last activity"), `createdAt`; the row key `type:id`.
- Each kind is an arm in ITS domain's plugin (`tasks/activity-arm`,
  `conversations/activity-arm`, `apps/pages/activity-arm`) — this plugin
  names none. An arm is declared `from` its entity (`liveArm(activity, kind, {
  from, pick })`), so every field a plugin exposes on that entity (a task's
  track, a conversation's cost, a page's tags) lands in the arm's band with no
  code here or in the arm.
- Where a row goes is its arm's: `activityLinks(arm, (row) => url)` — an
  app-rooted URL (`route.link(app, params)`), navigated cross-app, because the
  list is hosted by Home and its records belong to other apps.
- The surface is `<ActivityDataView>`; Home mounts it
  (`apps/home/recent-activity`). Its views are config
  (`config/activity/activity.jsonc`): Recent, and one per kind (a filter on
  `type`).

## Adding a kind

An `activity-arm` sub-plugin of the owning domain: `core` — `liveArm(activity,
kind, { label, order, from: entityRef, pick? })`; `server` —
`activityServed.arm(arm, { from, id, base, extra, where? })` in `register`
(`base` binds `title`, `updatedAt`, `createdAt`); `web` —
`FieldPresentation.Register({ owner: arm, fields })` (required, even empty)
and `activityLinks`. One arm per entity (the union refuses two arms reaching
one entity).

## Known limits

- A **page's** last activity is its row's `updated_at` (rename, move), not its
  content edit time: `editedAt` reads the `page_content_edited_at` rollup, a
  join only the `all` compiler takes, not a union arm.
- A **task's** does not move while an agent works on it — its conversation's
  row does.
