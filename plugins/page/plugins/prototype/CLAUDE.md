# prototype

The `/prototype` page block: links a prototype (`proto-…`, see
`apps/prototypes`) into a page. An agent that built a mock links it with
`<prototype id="proto-…"/>` (inside its `<agent-inline>` card, like any other
block); a human picks one from the `/prototype` picker.

- **At rest** the block is the prototype's rendered preview (the gallery's
  cached thumbnail — no live document per block) over a footer row: title,
  blurb, Open beside (the canvas as a column to the right of the page) and a
  new-tab arrow into the Prototypes app.
- **Click the preview** to play it live in place (the canvas's sandbox, at the
  block's width); Done goes back to the picture.
- **Markdown**: `<prototype id="…" title="…"/>`, body-less. `title` is annotated
  (read-only, from the prototype's `<title>` via `Editor.BlockAnnotation`), so
  an agent reading the page can tell mocks apart; it is dropped on parse. A
  non-`proto-` id is rejected loudly.
- Resolution is `prototypesList` (live, app-wide); an id it does not carry
  renders "(prototype not found)", which re-opens the picker.
