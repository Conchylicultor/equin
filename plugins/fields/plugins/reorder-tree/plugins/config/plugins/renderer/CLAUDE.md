# renderer

The reorder-tree field's **Config pane renderer** — a slot's layout as the
drag-and-drop editor (`reorder/editor`, dnd-kit) — and its `Fields.Sample`.

A plugin of its own, apart from `fields/reorder-tree/config` (the factory and
`normalizeNode`), because the APPLY path imports that one: reorder's slot
middleware ships in every served bundle and builds its directives with
`reorderTreeField`. A composition's closure is per plugin, so a renderer living
in the same plugin as the factory would put the layout editor in every bundle
(`reorder:apply-is-lean`). Editing a layout ships only where this plugin does.
