# enum / filter

The **enum** (select) type's `data-view.filter` capability.

Contributes `DataViewSlots.Filter({ match: "enum", domain: "text", ... })` —
`is` / `is not` (single option chip) and `is any of` / `is none of` (multi-select
chips over `field.options`), plus `is empty` / `is not empty`. Each operator
`lower`s into the one filter language (`network/live/plugins/filter`): `is` →
`eq`, `is not` → `ne`, `is any of` → `in`, `is none of` → `notIn` (exact,
case-sensitive option ids). An empty operand / empty selection lowers to
`undefined` (incomplete: keeps every row, not counted). `is not` / `is none of`
are complements, so a row with no option matches them.

An option's `value` is its value's canonical spelling (`fields/core`'s
`optionKey`), so the lowering reads it back: the option `"null"` is the
no-value (`is "null"` → `isEmpty`, `is-none-of [a, "null"]` → `notIn [a] ∧
isNotEmpty`), and over a field's `valueDomain` (`"boolean"` / `"number"` — an
enum over a probe verdict's `true` / `false`) each option lowers as the value
it spells (a boolean list as one `eq` per value, since a boolean column takes
no `in`). A key spelling no value of the domain names nothing. Lowerings live in
`web/internal/enum-lower.ts`, pinned by `enum-lower.test.ts`.
