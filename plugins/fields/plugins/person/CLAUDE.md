# person

The **person** field type — a person's display name, free text.

Registers its `FieldIdentity` with `extends: textFieldType`, so sort, the text
filter operators, grouping and the inline editor come from `text` through the
`extends` chain. It overrides only the cell (`plugins/table`: a small
`primitives/avatar` disc carrying the name's initial, its colour derived from the
name, beside the name). The factory is `personField` (`plugins/config`); the DB
column is a plain `text` (`plugins/storage` — storage resolves by exact token, so
the type declares its own builder).
