# bytes

The **bytes** field type — binary data (a Yjs doc state) whose value on the
wire is its unfolded base64 string and whose column is a Postgres `bytea`.

The field's value and schema are the WIRE form (`string`); `bytesField()`
marks its def `StoredAs<Uint8Array>` (fields/core), so an entity's table types
the column by what it stores while its wire schema stays the string. The
storage sub-plugin contributes the `stored` arm of `Fields.Storage`: the
`bytea` column, whose wire form is declared once through sql-column's
`withWire` — `serveCollection` encodes every served row with `bytesToBase64`.

Registers only its `FieldIdentity`: no cell or filter — no list shows a blob.
