# identifier

The **identifier** field type — a code identifier (a commit sha, a run id, a
fingerprint, a slug, a tool name): a string a person copies and compares, never
reads as prose.

Registers its `FieldIdentity` with `extends: textFieldType`, so sort, the text
filter operators, grouping and the inline editor come from `text` through the
`extends` chain. It overrides only the cell (`plugins/table`: the code role,
truncated, the whole value in its tooltip, a hover-revealed `CopyButton`). The
factory is `identifierField` (`plugins/config`); the DB column is a plain `text`
(`plugins/storage` — storage resolves by exact token, so the type declares its
own builder).
