# framework

The critical harness infra: the plugin runtime (web/server/central loaders, slots, registries), the `./singularity` CLI and the build-time tooling (checks, lint, codegen, boundaries) that every other plugin stands on.

- **Not a home for sharable primitives.** A reusable building block — a hook, a component, a helper, a data structure — goes under the umbrella it belongs to (`plugins/primitives/…`, `plugins/packages/…`, `plugins/infra/…`, `plugins/network/…`), even when many plugins use it. Being widely shared does not make code framework.
- Only code the harness itself needs to run, load or check plugins belongs here.
- Changes here are load-bearing for everything above it — design them carefully, keep them minimal.
