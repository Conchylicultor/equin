# install

`./equin install` — install this checkout's `node_modules` and exit.

The work is the bootstrap's: `bin/index.ts` runs `ensureDeps()` before every
verb, so this command's body only confirms the stamp. It exists so creating a
checkout has a step to run: `infra/worktree` spawns `<checkout>/equin install`
(the checkout's OWN CLI, install code and lock — `server` may not import `cli`)
after every checkout it makes, so a checkout is installed before anything runs
in it. Design: [`research/2026-10-28-global-checkout-installed-before-it-runs.md`](../../../../../../research/2026-10-28-global-checkout-installed-before-it-runs.md).

**Frozen through env, not a flag.** The install runs before argv is parsed (the
bootstrap reads no argv — see `cli/CLAUDE.md`), so `--frozen-lockfile` here
could never reach it. The spawner sets `EQUIN_FROZEN_LOCKFILE=1` instead, and
the bootstrap's `ensureDeps` call reads it, for any verb.
