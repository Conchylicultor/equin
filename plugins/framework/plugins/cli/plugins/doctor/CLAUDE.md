# doctor

Names **every** missing prerequisite of a dev checkout in one run, each with the
command that fixes it — instead of each one surfacing on its own, several only
minutes into a build (the clean-VM install of 2026-09-18 met them one at a time).

`doctor.sh` is the check, and the only copy of it. POSIX sh because its most
important case is Bun itself missing. It runs from the checkout it checks (cwd):

| who runs it | when |
|---|---|
| `mise run doctor` (`[tasks.doctor]` in `mise.toml`) | by hand, and at the end of every `mise install` (the `postinstall` hook) |
| `assertPrerequisites()` (`cli/`) | first step of `./equin start` and a deploying `build` — not `--hermetic`, not the release launcher: a bundle needs no dev toolchain |
| the `./equin` wrapper | when `bun` is not on PATH, before failing |

What it checks: not root; Xcode command-line tools (macOS) and a working git;
mise installed and active in the shell (`MISE_SHELL` set, or its shims on PATH —
tool install dirs on PATH do not count, since `mise run` adds them itself); every
shim resolving (a symlink loop or a missing target is named with
`mise reshim --force`); shims NOT installing tools on first use
(`not_found_auto_install` off — `mise run setup` sets it); the
locked toolchain installed (`mise install --dry-run-code`, tools named by
`mise ls --missing`). Every one is a `miss` and fails the run.

Claude Code is **not** checked: the app runs the build the Agent SDK ships
(installed with the dependencies, after the doctor runs), and the user signs in
from the app (`infra/claude-cli/plugins/sign-in`).

It asks only "is it there". Which release — floors, holds, something shadowing
mise — is `toolchain:resolved`'s job (`plugins/toolchain`). The tool list is
mise's, read from `mise.toml` + `mise.lock`, so adding a tool there needs no
change here.

The two shim checks come from one incident (2026-09-27): an agent ran `bun` in
a cloned third-party repo pinning another Bun, the shim installed it, and the
reshim that followed — run from inside the shim — linked every shim to
`shims/bun` and that to itself, so no backend could start. Shims that never
install cannot reshim; the loop check names the state if it happens anyway.
[`research/2026-09-27-global-mise-shim-self-loop.md`](../../../../../../research/2026-09-27-global-mise-shim-self-loop.md).

Git hooks are not checked: mise's `setup` task sets `core.hooksPath` on every
`mise install`.
