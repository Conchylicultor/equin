# foreground-handoff

A `check` or `test` an agent runs in a **foreground** Bash call, made unable to
die at the call's time limit.

## Why

A foreground call is killed at 600 s with `Command timed out` and nothing else:
no task id, and the CLI's orphan guard kills the op with its shell. So the
`background-ops` guard used to force every op into the background — which, for
`test` (p50 35 s) and `check` (p50 192 s), cost a turn end and a re-invocation
for a result often seconds away, and refused every other command typed in the
same call. Simply allowing the foreground would not do: past 570 s, host-grant
queue included, are 11% of tests and 20% of checks (op-log, 30 days).

## How

1. The `foreground-deadline` guard (tooling/guards) sees a foreground call
   running a hand-off op, raises its timeout to 600 s and exports
   `EQUIN_FOREGROUND_DEADLINE` = now + 600 s − `HANDOFF_MARGIN_MS` (60 s).
2. The CLI mapper (`cli/bin/register-commands.ts`) sees the deadline on a
   top-level hand-off command and calls `runHandedOff` instead of the action.
3. `runHandedOff` re-runs the same argv as a **detached** child (own process
   group, stdout/stderr to a temp file, `OP_HANDED_OFF` set so its orphan guard
   stays off, the deadline unset so nothing below it hands off again) and
   streams the file to its own stdout.
   - The op finishes in time → its exit code is the call's. Indistinguishable
     from running in place.
   - The deadline comes first → print the hand-off (pid, `./equin await <op>`,
     the output file), exit **70** (`await`'s "still running"), leave the op
     running.
   - The launcher is interrupted or orphaned first → SIGTERM the op's group,
     as an in-place op would have died.

The launcher is not an op: it writes no marker and takes no grant. The child is
the op, so `./equin await` finds it by its marker like any other.

`FOREGROUND_HANDOFF_OPS` (`core`) is the one list both the guard and the mapper
read. Adding an op = adding it there; `build` / `push` / `release` are not on it
because most of their runs would hand off anyway.
