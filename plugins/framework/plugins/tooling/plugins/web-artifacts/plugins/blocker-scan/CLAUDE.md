# blocker-scan

Content blockers cancel requests by URL. EasyList, EasyPrivacy and uBlock
filters (on by default in uBlock Origin / uBO Lite, AdGuard, Brave Shields)
carry ~5,600 **generic** rules — no domain named — such as `/fingerprint.js^`,
`/beacon^` or `/autotrack.`. A served URL is spelled from source file and
plugin names (`/artifacts/<plugin-id>.<kind>.<hash>/core/fingerprint.js`), so a
file named like a tracker silently fails to load — with every importer — for
those visitors, while curl, headless Chromium and our e2e runs load it fine.
That broke the demo's worker boot (EasyPrivacy #8404, `/fingerprint.js^`;
report-1794652463-yjt4cc).

The daily `web-artifacts.blocker-scan` job (main only — a schedule's default —
in a supervised child) runs `./equin web-artifacts-blocker-scan`:

1. **Rules**: `ensureDep(blockerRulesets)` — uBO Lite's Chromium release zip
   (`deps/`), a `githubReleaseDownload` whose pin
   (`deps/internal/ubol-rulesets.pin.json`) the `github-release` updater
   (`infra/deps/download/github-release-updater`) moves to each new release
   past a 3-day cooldown. The derive keeps the rulesets uBO Lite enables by
   default (`ruleset-details.json`'s `enabled`) with their block / redirect
   rules. Never committed: the lists are GPLv3 / CC BY-SA, the repo Apache-2.0.
2. **Which rules** (`core/`'s `isGenericCancellingRule`): block or redirect,
   no `requestDomains` / `initiatorDomains`, no `||host`, not third-party only,
   not excluding our hosts (`SERVED_HOSTS`), applying to GET. Compiled with DNR's
   urlFilter semantics (`*`, `^`, `|`, case-insensitive unless the rule says);
   a `regexFilter` JS cannot compile is printed as not checked.
3. **Which URLs** (`cli/internal/served-urls.ts`): main's namespace dist — its
   served graph's names (`servedGraphOf`, the record address retention keeps)
   walked under `/artifacts/`, plus the dist's own files — and each release
   dist under `<main>/release-web/` (what ships to equin.ai), walked whole. Each
   path is tested from `https://equin.ai` and `http://equin.localhost:9000`,
   against the resource types its extension can be fetched as.
4. **Hits** file a `blocked-artifact-url` report (`server/`'s kind, error) per
   (source file, rule) through the report outbox, the source found from the
   artifact's `meta.json` (`pluginPath`) and the path inside it; a route
   chunk, vendor file or dist asset files with `source: null`, keyed by its
   path with the hashes taken out. A source this checkout no longer has (an
   older build's file) is printed, not filed; a filed source carries `code`
   so the drain drops it once main has changed the file.

The fix for a hit is a name the rule does not match (rename the file or the
plugin), never an allowlist. `./equin web-artifacts-blocker-scan --dry-run`
prints the hits without filing.

Not in `./equin build` or `./equin check`: the rules move upstream without a
commit of ours, and builds must not depend on GitHub being up.
