# bypass

The one spelling of a guard bypass, shared by the hook (`guards/core/runner.ts`,
which records and consumes it) and the CLI verb (`guards/cli`, which confirms it).

A denial names its call's **bypass id** — `<guard>#<hash>`, the guard plus a hash
of the exact call it refused (`repeatKey`). An agent that is SURE the call is
safe runs `./equin guard bypass <id> --reason "<why>"` as its own call, then
retries the call unchanged: that one call goes through that one guard. Never a
standing permission — nothing is bypassed by default, a bypass covers one call,
and the reason is in the transcript for whoever reviews it.
