# dom-access-safety

Contributes two repo-wide ESLint rules. `no-module-scope-dom`: in `plugins/**/web/**`,
a browser global (`window`, `document`, `navigator`, `localStorage`,
`sessionStorage`, `matchMedia`) may not be read **during module evaluation** —
that runs on import, making every importing module unloadable under `bun test`
and the docgen barrel walk. Reads inside a function/hook/component body are the
fix and are never reported. For a socket URL use `wsUrl` from
[`@plugins/primitives/plugins/networking/web`](../../../../../../../primitives/plugins/networking/CLAUDE.md).

Two deliberate holes, both load-bearing:

- **`typeof <name> !== "undefined"` guards pass.** They degrade to a skipped
  branch off-browser instead of throwing — the right shape for a module-scope
  listener registration (`primitives/pane/web/pane.ts`, `parse-keys.ts`).
- **`exempt/index.ts` holds only the two Vite entry points** (`web-core/web/main.tsx`,
  `layout-harness/…/entry.tsx`). They are loaded by a `<script type="module">`
  tag and never statically imported, so no module graph can reach them. Nothing
  else qualifies — put the read in a function instead.

Rationale and the failure it came from:
[`research/2026-08-08-global-module-scope-dom-import-safety.md`](../../../../../../../../research/2026-08-08-global-module-scope-dom-import-safety.md).

## `no-root-style-write`

Nothing writes `<html>`'s inline style — `document.documentElement.style`, or
`.style` of a `const` bound to a `documentElement`. A custom property or style
set on the root is inherited by every element, so each write forces a
whole-document style recalc (300–450 ms on an 18k-element page). Root-level
styling is the theme engine's, through its stylesheets. Anything else sets its
value on the subtree that reads it: a rule keyed on that subtree's own class in
an adopted `CSSStyleSheet` (how `shell/global-action-bar` publishes the floating
bar's safe area — ~5 ms per write instead of ~300), or an inline style on that
element. The one exemption is `embed/frame/agent`, which styles the root of a
prototype's own frame document.
