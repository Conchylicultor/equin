# backstop

The two-program type check's safety net. A `type-check` run re-checks only the
files with no valid stored result and what their changed names reach, and
reuses every other file's stored diagnostics and `.d.ts`
(`../../shared/name-run.ts`). Nothing in a check run can notice a key or an
affected set that misses something a file's check reads, so once a day this job
runs the worker in `dual` mode on main: the two-program check, then a full
check of a fresh whole program (`../../shared/full-check.ts`), compared file by
file.

- A divergence is logged (`logs/type-check-backstop.jsonl`) and filed as a
  `type-check-divergence` report (one row per file and kind), and a cold run
  rewrites the store. The fix is always to widen the key or the affected set,
  never to delete entries.
- Reproduce by hand with `../../scripts/dual-check.ts` on the trees before and
  after the commit in question.
- Main only (a scheduled job's default), in a supervised child: a background
  grant of the DUAL weight (`typeCheckWorkerUnits("dual")`, from the measured
  `TYPE_CHECK_BACKSTOP_PEAK_BYTES` — the oracle is one unbatched whole program,
  far heavier than a batched worker), then a worker slot. The grant is RIGID
  (`min: max`): unlike a batched worker the oracle cannot shrink to a short
  grant, so it waits for its whole weight rather than run ~16 GB on a share of
  a few — and an inherited grant smaller than the weight is refused. Not part of any
  build. Its run is recorded in the worker memory log like every worker's
  (`spawnTypeCheckWorker`), with the oracle's footprint, and
  `type-check:worker-weight-measured` holds the weight to it. The transcript's
  `backstop at …` line prints the worker's, the oracle's and the batches'
  peaks.
- The child is the `./equin type-check-backstop` command (`cli/`), not a
  `run` body: the backend imports a `run` body to schedule it, and this one
  would put the check runner in the serving backend's closure
  (`boot:closure-digestable`). Run it by hand to reproduce a nightly run.

Design: `research/2026-10-21-global-type-check-two-programs.md`.
