# conversation-trailer

Fails unless `SINGULARITY_CONVERSATION_ID` is set and every one of this
branch's own commits carries a `Singularity-Conversation` trailer naming it
(stamped by `.githooks/prepare-commit-msg`), so the pushes ledger can attribute
the push to its task.

"This branch's own commits" are those reachable from `HEAD` and from no `main`
the checkout knows of: local `main` and every `refs/remotes/<remote>/main` — the
same published set `database/migrations` reads. After `./singularity upstream
merge`, a clone's branch carries upstream's commits, which are on
`<remote>/main` but not on local `main`; they were written in upstream's own
sessions, so their trailers are not this pane's to have.
