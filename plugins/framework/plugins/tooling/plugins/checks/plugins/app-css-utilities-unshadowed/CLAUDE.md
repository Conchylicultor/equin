# app-css-utilities-unshadowed

Fails when a custom `@utility` in
`plugins/primitives/plugins/css/plugins/ui-kit/web/theme/app.css` claims a
class a stylesheet it imports also declares (`@import "shadcn/tailwind.css"`
and any other package sheet; Tailwind's own `tailwindcss` import is skipped).
An equal name, or a functional `<prefix>-*` covering the other, is a clash.

Tailwind merges two `@utility` rules of one name into one class without a
word, so a package upgrade that adds a utility we already have silently adds
its declarations to ours. That is how shadcn 4.23's `scroll-fade` (a
`mask-image` edge fade) merged into our `scroll-fade` (sticky gradient strips)
and clipped every overlay panel's ring and shadow — menus lost their edge in
every theme. The fix is a rename on our side (`scroll-edge-fade`,
`hide-scrollbar`); this check keeps the next upgrade from doing it again.
