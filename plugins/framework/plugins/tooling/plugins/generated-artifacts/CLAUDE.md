# generated-artifacts

The one list of the repo's committed generated artifacts — files a build (or
the migration generator) writes, never a person. Each entry is a gitattributes
path pattern plus the merge driver that resolves it after a merge
(`regen-generated` / `regen-migrations`, `plugins/framework/plugins/cli/scripts/`).

- **A zero-import leaf on purpose.** `codegen/core` imports `fs` at module
  scope, so the browser cannot reach it; this list is read by web code too
  (`code-explorer/file-kind` classifies a commit's files as `generated`).
- **`.gitattributes` must agree.** The `generated-artifacts-attributed` check
  fails when a `merge=regen-generated` / `merge=regen-migrations` line and
  `GENERATED_ARTIFACTS` differ — add a new artifact in both places.
- Mixed files (`plugins/**/CLAUDE.md`, `merge=regen-claudemd`: hand-written
  prose plus an autogen block) are not generated artifacts and are not listed.
