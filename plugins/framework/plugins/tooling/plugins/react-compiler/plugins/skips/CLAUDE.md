# react-compiler/skips

When the React Compiler cannot compile a component or hook, it emits it
unchanged: no memoization, so every render of it re-renders its whole subtree.
It says so nowhere — the build passes, and the react-hooks lint rules run the
compiler with other options and report only some categories. Places' search
re-rendered ~1,000 components per keystroke through two such skips
(report-1795084621-fswh11).

## `react-compiler:no-silent-skips`

`check/index.ts` runs the compiler over every module the browser build
compiles (`web/`, `core/`, `shared/`, `exhibits/`; tests out of scope) with
**the build's own options** — read off react-compiler's `vite/index.ts`, the
one file the artifact builder reads, and with the same compiler version
(asserted: the build's and this plugin's `babel-plugin-react-compiler` must
resolve to one version). Every function it leaves uncompiled fails the check
unless the plugin owning the file declares it in its own `exempt/index.ts`:

```ts
{
  rule: "react-compiler:no-silent-skips",
  paths: ["web/components/x.tsx"],
  kind: "debt", task: "task-…", // or "sanctioned"
  reason: "…",
}
```

It is a fold check (`defineFoldCheck`): each file's skips are a record keyed by
its bytes and the scan module's closure (the compiler included), so a pass
after an edit compiles only the edited files; a compiler upgrade re-folds
all of them. An exemption that no longer matches fails the check too — remove
it when you fix the file.

What it reports, and the usual rewrite:

- **`Todo`** — syntax the compiler does not lower yet: `try/finally`, a `try`
  without `catch`, `??=`, `x++` on a variable a closure captures, a computed
  key in a destructure. Move the async body into a plain module-level
  function, spell `x = x ?? v`, use a local or a ref.
- **`Hooks`** — a hook carried as a value (`props.useX()`,
  `descriptor.useContributions()` — the `Hook<F>` pattern of
  `framework/hook-value`), a hook called in a lambda, or conditionally. The
  conditional case is a real bug (it found one in `auth`'s
  `ScopeGrantNotice`, a hook after an early return that `rules-of-hooks`
  missed through `Auth.ScopeRequirement.useContributions()`).
- **`Suppression`** — an `eslint-disable` of `react-hooks/exhaustive-deps` or
  `react-hooks/rules-of-hooks` makes the compiler skip the function holding
  it. **A block `/* eslint-disable … */` skips every function in the file,
  even with its `eslint-enable`**: the compiler (1.0.0) records the range
  before it reads the enable comment, so the range never closes. `pane.ts`
  lost 35 router hooks and `use-live.ts` 11 read hooks to one block each.
  Use `eslint-disable-next-line`. A memo listing a dep it never reads (a
  version signal) must stay uncompiled: the compiler infers deps from reads
  and would drop it — and `void dep;` does not help, it is dead code the
  compiler deletes (`pane.ts`'s `useRoute`).
- **`PreserveManualMemo`** — a hand-written `useMemo` / `useCallback` whose
  deps the compiler cannot keep. Drop it and let the compiler memoize.
- **`Refs`**, **`IncompatibleLibrary`**, **`Invariant`** — a ref read in
  render, a library the compiler refuses (`@tanstack/react-virtual`), a
  compiler internal error.

`"use no memo"` is an explicit opt-out written in the code, not a silent skip,
and is not reported.

## What a skip costs: `e2e/render-cost.ts`

A devtools hook installed before React counts, per commit, the components that
rendered and which of them re-rendered because their nearest rendering parent
was not compiled (a compiled component carries its memo cache on its fiber,
`updateQueue.memoCache`, so the split needs no source map). A component the
compiler compiled with nothing to memoize has no cache either, so the
"not compiled" side is an upper bound.

```bash
./equin run plugins/framework/plugins/tooling/plugins/react-compiler/plugins/skips/e2e/render-cost.ts \
  --path /agents/tasks --steps "wheel:1500|type:Search:ab" [--url http://equin.localhost:<port>]
```

Measured on main (2026-11-19), before this check: scrolling and searching the
task list, the reports list and a conversation, 0–3 % of the components
rendered came from a non-compiled parent; typing in a conversation's prompt,
~14 %, mostly a third-party editor component. The remaining skips are debt
(`./equin exempt list --rule react-compiler:no-silent-skips --debt`).
