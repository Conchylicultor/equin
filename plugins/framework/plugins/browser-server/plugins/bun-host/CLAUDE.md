# bun-host

A browser host's server graph booted in Bun instead of a worker — the website's
crawl snapshot take (`apps/website/crawlable/bin/static-host.ts`) and the
workspace demo's snapshot take and boot test (`demos/workspace/bin/`).

```ts
await bootBrowserHost({ entries: withDiskProviders(hostEntries, hostProviders), … });
```

The worker bundles two providers whose data is text inlined by vite's
`import.meta.glob`, which Bun cannot evaluate: the migration history
(`database/migrations/bundled-source`) and the committed config layer
(`config_v2/bundled-layer`). `withDiskProviders` swaps each for an entry
providing the same service from the same files read off disk; every other entry
is the worker's. A swapped provider must be exactly one entry of the graph and
provide that one service only, or it throws.

Not for tests booting a registry slice: `test-host`'s `withPortableHost`
derives the providers itself (and reads the same files through its own
lazily loaded entries, so a graph without those owners declares none of their
services).
