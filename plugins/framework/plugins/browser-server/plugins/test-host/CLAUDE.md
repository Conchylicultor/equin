# test-host

Boot a slice of the app's server registry as a portable host (a host without
the computer: PGlite, the in-process queue, the memory stores) in a `bun test`
process — for a suite proving some plugin's server closure runs portably.

```ts
// In a FRESH child process (a boot registers its graph process-wide).
await bootPluginGraph({
  mode: "exec",
  entries: await withPortableHost(registryClosureOf([SUBJECT])),
});
// or, as a browser host boots (only portable edges followed):
await bootBrowserHost({ entries: await withPortableHost(await portableClosureOf(roots)), … });
```

- `registryClosureOf(roots)` — every `dependsOn` edge (the desktop's edges, for `exec` mode).
- `portableClosureOf(roots)` — only edges to portable server barrels, as `browser-host-gen` keeps them.
- `withPortableHost(graph)` — the graph plus what the host boots beside it,
  **derived, never hand-listed** (a hand-kept provider list went stale each time
  a closure reached a new host service): one host provider per declared service
  to a fixpoint, the committed migrations / config read off disk (Bun has no
  `import.meta.glob`, which the bundled providers use), and in-memory host
  storage declared.
