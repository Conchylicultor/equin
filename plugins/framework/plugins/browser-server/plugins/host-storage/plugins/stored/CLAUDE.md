# stored

Whether this browser already holds a persistent browser host's data —
`hostDataStored(name)`: its lifecycle record says `ready` — read without
booting anything and without creating the database when it is absent
(`indexedDB.databases()` first). A page asks it before deciding to start a
host: `demo/scope`'s gate (a first visit waits for Enter equin, since starting
downloads the whole server and its data) and `demo/prestart` (the head start
runs on a return visit only).

It also owns the IndexedDB layout it reads (`layout.ts`: the storage's
database names, the entries and meta stores, the lifecycle record), which
`host-storage`'s open writes — one spelling for both. A leaf, so a page's head
script can import it without the rest of host-storage.
