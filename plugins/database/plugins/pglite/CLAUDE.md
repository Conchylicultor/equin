# pglite

The PGlite database driver: a `DatabaseDriver` (`database/server`'s host
service) over Postgres compiled to WASM, running in this process — for a host
without the computer's Postgres cluster. The desktop never boots it: it is in
`base-exclusions` (`plugin-meta/composition`), and its own `pgDriver`
(`database#machine`) is the desktop's provider. A composition that runs without
the computer names it to take it back.

- **In memory by default** (`createPgliteDriver({ dataDir? })`): the database
  lives and dies with the process. A browser host would pass an `idb://` dir.
- **Scripts go through `exec`.** node-postgres runs a parameterless query over
  the simple protocol, which accepts several statements (a migration file, a
  view rebuild); PGlite's `query` is extended-protocol, one statement only. The
  driver routes a parameterless, non-array-mode query through PGlite's `exec`
  and answers with the last statement's result — decided up front, because
  inside a transaction a failed attempt would abort it.
- **`bootDdl` adds no bound**: one connection, nothing else holding locks.

Proven by `tasks/task-category`'s portable boot test, which boots that plugin's
whole server closure on this driver.
