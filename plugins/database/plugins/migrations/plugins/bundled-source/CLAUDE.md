# bundled-source

The `MigrationSource` (`database/migrations`) of a host without the repo on
disk: the committed `data/*.sql`, inlined into the bundle as text at build time
(`import.meta.glob(…, { query: "?raw", eager: true })`), fed through the same
`migrationsFrom` the disk source uses. Only a vite-built bundle can boot it —
`import.meta.glob` is vite's — which is exactly the browser worker host
(`framework/tooling/web-artifacts`' browser hosts). The desktop never boots it:
it is in `base-exclusions` (`plugin-meta/composition`), and `migrations#machine`
is the desktop's provider.
