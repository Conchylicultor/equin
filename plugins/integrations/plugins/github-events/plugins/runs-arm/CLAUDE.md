# github-events/runs-arm

The GitHub arm of the merged run space (`runs`): every run attempt of a watched
workflow (`GitHubEvents.Watch` — the product repo's installer release, i.e. the
publish of a cut release, and the embedded packages' daily Build and Publish)
is a row of the runs list, kind `github`, beside the builds and releases that
lead to it.

- **Outcome** — not `completed` → `running`; completed → its conclusion
  (`success` / `neutral` / `skipped` → succeeded, `cancelled` → canceled,
  `action_required` → needs-approval, anything else → failed).
- **Times** — `github_runs.started_at` (`run_started_at`) and `finished_at`
  (the run's `updated_at` once completed), stored at ingest.
- **Label** — `<workflow> · <head>`; **trigger** — GitHub's event;
  **message** — the failed jobs' names.
- **Click** — opens the run on GitHub (no detail pane here).
