# resend

A stateless client for [Resend](https://resend.com)'s send-email API, in the
style of `integrations/google-maps/places-api`: the key is a parameter, and the
plugin knows nothing about who sends or why.

- `sendEmail(apiKey, { from, to, replyTo, subject, text }, { signal? })` — one
  `fetch`, no retry (retrying is the caller's policy, usually a job's).
  - An answer is always `{ ok: true, id } | { ok: false, status, error }`; a
    2xx without an id is a failure, so nothing reads as sent unless Resend
    said so.
  - No answer (DNS, connection, an aborted `signal`) throws fetch's error.
- `from` must be on a domain verified in Resend (SPF + DKIM records).

First consumer: `apps/deploy/site-messages/intake`'s notify job.
