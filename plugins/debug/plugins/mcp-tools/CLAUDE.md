# mcp-tools

Debug → MCP tools (`/debug/mcp-tools`): every tool the worktree's MCP server
hosts, read from the `mcp.catalog` live value (`infra/mcp` core), and a detail
pane per tool (`/debug/mcp-tools/tool/<name>`).

- **The registry is the source.** `infra/mcp` builds the catalog from its own
  registry, recording each contribution's declaring plugin at register time
  (`registeringPlugin()`), so nothing can be callable without a row here.
- **The schema shown is the one agents get.** Each tool's input schema is read
  off a real `tools/list` (every tool mounted the way a request mounts it,
  listed over an in-memory client), never a second zod → JSON conversion.
- **Per-conversation facts are flagged, not evaluated.** A `when` gate and a
  `liveDescription` depend on the conversation, so the page says a tool has
  one (`gated`, `live`); it does not run them.
- The server instructions sections and the scope resolver (also contributions
  of `infra/mcp`) are summarised above the list, with their declaring plugins.
