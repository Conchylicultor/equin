# sink

The public channel into the client slow-op queue — `clientSlowOpSink`, an
observation sink (`primitives/report-sink`) — and `CallerRef`, who issued an
operation. A producer outside slow-ops (`reports/main-thread-stall`) emits a
fully-formed slow op into it; slow-ops' collector, when mounted, forwards each
emit to the client beacon, and an emit with no collector mounted is dropped.

A core-only leaf because a composition's closure is per plugin: a producer
importing the sink from `debug/slow-ops` bundled slow-ops whole (its pages, the
trace engine, the boot profile) wherever the producer shipped — the in-browser
demo included, which cannot serve them. The same neutral-sink shape as
`primitives/report-sink`.
