# background

Debug → Background activity (`/debug/background`): the panes and sidebar entry
over the background catalog (`infra/background/catalog`), whose web barrel
owns the list and detail components this plugin mounts.

The split is load-bearing. The catalog is infrastructure every backend with
jobs or timers depends on, and composition closure is per plugin — so while the
catalog's own web barrel registered these panes, any composition that ran a job
(the website, via analytics) shipped the whole Debug app, which then won the
bare-`/` redirect. Nothing under `infra/` may import the Debug app.
