# health-row

The health report's **Machine watcher** row, split from `debug/sentinel` so a
composition can leave the row out without losing the sentinel (the showcase
film's composition does: the row reports the developer machine — main's
watcher restarting with main — never the film's story). What the row shows,
and the `sentinel.status` / `sentinel.vitals` values it reads, are documented
in the parent's CLAUDE.md ("When the watcher dies", "What the watcher measures,
on the row"); the view model is pure (`web/internal/vitals-view.ts`,
`web/internal/machine-watcher-health.ts`), tested in `web/__tests__/`.
