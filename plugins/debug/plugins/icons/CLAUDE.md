# debug/icons

Debug → Icons (`/debug/icons`): every icon name the app draws, as every icon
family draws it. Plan: `research/2026-10-23-global-agent-icon-family.md` §4.

- **Rows** — the build's icon manifest (`icons.manifest`, a `liveValue` served
  by `ui/icons/sprites`: the `symbol("…")` names the sprites ship). No
  call-site counts: the manifest records names only. Then every shown inline
  family's **app-only glyphs** (`appOnlyGlyphs`: its `glyphs` keys no
  `symbols` value maps — what only `family.icon("…")` draws), one Coverage
  group per family ("<Family> only"), each drawn as its `CustomRef` in its own
  column and blank ("not in this set") in every other. A hidden family's
  glyphs leave with its column; they never fall back, so Fallbacks only drops
  them.
- **Columns** — Material (the built-in base) plus every `useIconFamilies()`
  family. No family or app is named in this plugin (collection-consumer
  separation): labels, kinds, coverage and fallbacks all come from the
  families.
- **Cells** — a real `<Icon>` under `IconFamilyPreview` (icons web), so the
  page draws what an app draws. Where the drawing comes from is
  `resolveIconSource` — the chain `<Icon>` walks: own (plain), fallback
  (dimmed, badged with the drawing family's initial), gap (a strict family's
  dashed gap glyph). A preview never files an `icon-family-gap` report.
- **Left list** — a `DataView` (`debug.icons.sets`): each app whose theme draws
  in an app-drawn (inline) family, with own/total and how far it is from
  strict (own/total and the fallback / gap counts are over the manifest's
  names only; the app-only glyphs show beside them as "+N own glyphs"); then
  the libraries (Material and sprite families) with the apps
  drawing in each. An app's family is the style the icons token bridge
  publishes for `app:<id>` (`useScopeIconStyles`). A click shows / hides the
  column.
- **Body** — one `DataViewSwitcher` surface (`debug.icons`) with two contributed
  sources: Matrix (table, grouped by the worst cell, app-only glyphs last) and
  By set (icons view, grouped by family, each family's app-only glyphs in a
  "<Family> · own glyphs" group right after it). Search, size (16/20/24/40), Active (every cell drawn
  `active` — each family's active form, derived or its own) and Fallbacks
  only apply to both. The page is an `IconMotionRegion`: hovering a row plays its animated
  glyphs.
- The model (`web/internal/model.ts`) is pure, tested with fake families.
