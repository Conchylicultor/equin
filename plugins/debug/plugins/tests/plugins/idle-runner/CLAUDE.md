# idle-runner

Fills Debug → Tests in while the host is idle (`infra/host/idle`):

- `host.idleBegan` → `tests.idle-began`: bring the checkout's digests current
  (`requestCheckoutDigests`); its end (`tests.digestsSettled`) →
  `tests.idle-next`.
- `tests.idle-next` (singleton, serial): only while `host_idle_state` is
  `idle` and no batch holds the `idle` lock, pick a batch with the pure
  `selectIdleBatch` (stale and last failing → never run → stale oldest; only
  when none: verdicts older than 7 days; ≤ 25 files or ≤ 60 s of last-known
  duration) and enqueue `tests.idle-batch`.
- `tests.idle-batch`: `./equin test <paths…>` in this checkout,
  `EQUIN_OP_OPPORTUNISTIC=1` (background lane, low priority, ignored by the
  ops blocker), `EQUIN_TEST_ORIGIN=idle`, `verdictExits: [TESTS_FAILED_EXIT]`
  (failing tests are data, never a dead-lettered job). Its `onEnded` ingests
  the record, then asks for the next batch.
- `host.idleEnded` → `cancelSupervisedJobByLock` (one batch lost at most).
- Files a batch of this idle period already took are not picked again (process
  memory, reset on `idleBegan`), so a file whose run yields no record cannot
  loop.

## Plugin reference

- Description: Runs stale and never-run test files while the host is idle: on host.idleBegan it brings the checkout's test digests current; each tests.digestsSettled (and each batch's end, after its record is ingested) starts the next tests.idle-batch — `./equin test` on files chosen by selectIdleBatch, opportunistic, origin idle — while the host is still idle; host.idleEnded cancels the running batch.
