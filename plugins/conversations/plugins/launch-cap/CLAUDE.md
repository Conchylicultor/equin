# launch-cap

The `agent-launch` config (`agentLaunchConfig`, core): `maxConcurrent`, the
host-wide cap on agents the auto-start queue runs at once. The cap itself is
enforced by the launcher in `conversations/server` (`internal/launch-cap.ts`,
`internal/launch-slots.ts`); this plugin only owns the config document.

A plugin of its own because `conversations/server` is not portable: a config
the web registers must be served by every host's graph (the in-browser demo
included), so it is registered from this portable `server/` barrel, the way
`hibernation` registers `hibernationConfig`.
