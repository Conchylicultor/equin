# workspace/launch-option

The **Workspace** launch option: where a task's agent runs — the worktree (the
default, stored as no row) or one registered scratch profile. Design:
[`research/2026-10-16-global-workspace-launch-option.md`](../../../../../../research/2026-10-16-global-workspace-launch-option.md).

- `core/` — `workspaceLaunchOption` (`WorkspaceSpec | null`, `null` = worktree).
- `server/` — the `tasks_ext_workspace` side-table; `TaskLaunchServer` validates
  through the kind's `parseSpec` (an unknown profile, or one whose input has no
  defaults, is a 400) and applies; `getTaskWorkspace(taskId)` is read by the
  conversation lifecycle when it creates a NEW attempt for the task. Not
  inherited.
- `web/` — the pill (menu lists `workspace.catalog`: every kind and scratch
  profile, details in a per-row hover card) and the task detail's select.
