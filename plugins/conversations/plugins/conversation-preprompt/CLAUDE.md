# conversation-preprompt

Records the preprompt a conversation's task was launched with as a snapshot on
the conversation, and surfaces it as a chip in the conversation header.

When a conversation is created, a job bound to the `conversationCreated` trigger
event resolves the launching task's selected preprompt and copies its id, title,
and full text into a `conversations_ext_preprompt` side-table (via the
entity-extensions primitive). The snapshot is intentional: the chip reflects
exactly what the agent was launched with, even if the config preprompt is later
edited or deleted.

The header chip (a `conversationPane.Actions` item) reads that snapshot from the
lookup-only collection `conversationPrepromptRows` (`liveCollection(
"conversation-preprompts", { row, id: "conversationId" })`, minting
`conversation-preprompts:rows` alone), served by `serveCollection` from the
extension handle. A reader subscribes to its one conversation
(`useLiveRow(conversationPrepromptRows, conversationId)` → pending / found /
not found) so a read costs O(1) rather than an O(n) lookup over the whole
table, and a write reaches only that conversation's subscribers. It is not
preloaded (a lookup-only collection cannot be): the row hydrates one
round-trip post-mount, so the chip and sidebar icon stay unrendered until it
lands. The chip renders the preprompt title; clicking it opens a popover with
the full instruction text.

## Boundary notes

`server/` is `portable: true` (the extension table, the live read, the
saved-icon source), so a browser host serves the snapshot from its own DB. The
`conversationCreated` trigger and `recordPrepromptJob` live in `machine/`: the
job resolves the preprompt through the preprompts library and task-preprompt,
which read config.

The recording is wired purely through the `conversationCreated` event binding —
this plugin is never imported by the load-bearing `conversations` lifecycle.
That keeps the dependency graph a DAG (conversations → conversation-preprompt,
never the reverse) and the feature fully opt-in and removable.
