# file-checkpoint

Renders Claude Code's rewind checkpoints in the JSONL viewer. Claude Code writes
a `type: "file-history-delta"` line right before the agent first changes a file
within a turn, backing up the file's prior state so `/rewind` can restore it
(`backup.backupFileName: null` means the file did not exist yet, so a rewind
deletes it).

The transcript parser
(`plugins/conversations/plugins/transcript-watcher/server/internal/parse-jsonl.ts`)
turns each line into `kind: "file-checkpoint"` (`path` absolute, `created`); a
line whose shape it does not recognise stays `kind: "unknown"`, keeping the raw
payload and the investigate action. The row is a one-line `EventLine`:
`Checkpoint <path> · new file` — the message ids, backup file name, version and
backup time are bookkeeping a reader never acts on (still reachable through the
row's raw-JSON action).
