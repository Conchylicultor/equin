# harness-nudge

`batching_reminder_sent` and `silent_turn_reminder` are the same fact: the
harness slipped the agent a one-line coaching note mid-session — *batch the tool
calls that don't depend on each other*, *say something so the user knows you're
alive*. One plugin, one component, because a reader cares about the same thing
in both cases and the two should not drift into two different-looking rows.

The row is a `CollapsibleCard`, closed by default. A nudge is not the agent's
turn and not the user's, and it is never the point of the conversation — it is
the machinery talking to itself. The closed row names *which* nudge (`Batching
reminder`, `Check-in reminder`); opening it shows the note's full text, wrapped.

Closed by default because these notes are near-identical every time they fire:
the batching reminder alone appears dozens of times in a long session, so an
open card would push the actual work off the screen. A card rather than a
truncated one-line `EventLine` because the note does not fit on one line, and a
reader who wants it should get all of it with one click, not via raw JSON.

`model` is not rendered — which model was being coached is plumbing, not
something a reader takes away from the row.
