# event-turn

Renders an `event` turn in the JSONL viewer: a turn the app (not the user)
delivered to a watching agent — a report, a flag, the subtree going quiet
(`tasks/orchestration/watch`).

The turn ledger types an `event` turn inside the `<equin-event>` envelope
(`turn-ledger/core/event-envelope.ts`, applied at accept, so no sender can
deliver one bare). The transcript parser (`transcript-source`'s
`parse-jsonl.ts`) recognises a user line whose whole text is that envelope and
emits `kind: "event-turn"` (carrying the line's uuid, which retires the
pending echo) instead of `user-text`; `userPromptText` returns null for it, so
a rewind never cuts there. This plugin's `EventRenderer` draws it as a dashed
system card, folded to its first line.
