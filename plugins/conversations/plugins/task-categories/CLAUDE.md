# task-categories

The task categories the conversation domain files under —
`CONVERSATIONS_CATEGORY_ID` (a bare launch, an adopted session, the agent
manager's home prompt) and `SYSTEM_CATEGORY_ID` (a system-kind conversation's
task), both declared in `conversations/core`.

Their `TaskCategory` registrations live here, in a portable barrel, rather than
in `conversations/server`, which files the tasks but needs the computer: a
browser host (the Agent Manager demo) lists tasks in these categories without
booting it, and its task list reads the labels from the registry. The
browser-host coverage guard's contributions arm
(`codegen/core/browser-host-coverage.ts`) is what keeps a category's
registration on every host that renders it.
