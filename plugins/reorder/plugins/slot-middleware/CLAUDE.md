# slot-middleware

Sub-plugin of `reorder`. Contributes reorder's list and item middleware to
`primitives/slot-render` (`SlotRender.ListMiddleware` / `ItemMiddleware`) as
**companions** (`companion: true`), so they ship in every composition that ships
slot-render. Without them every render slot silently falls back to raw
registration order and ignores its committed `config/**/<slot>.jsonc` layout
(equin.ai once shipped that way).

Why a sub-plugin rather than reorder's own barrel: reorder's `contributions` is
the live array the slot-declaration pass rewrites (one config directive per
reorderable slot), and a companion must sit in an inline `contributions: [ … ]`
literal for the closure engine to read it (`companions-visible` check). Its
import of `@plugins/reorder/web` pulls reorder itself into the bundle.

The middleware still both APPLIES a layout and hosts the drag surface, so the
DnD editor rides along. Splitting the two — so only "apply" is a companion — is
the open follow-up on the runtime-companions track.
