# editor

The **presentational** drag-and-drop reorder editor behind the Config pane's
`reorder-tree` field — the one place a slot layout is edited in the app (the
other is its `config/**/<slot>.jsonc` file). Never part of `reorder`'s apply
path, which imports none of it (`reorder:apply-is-lean`).

- **`ReorderEditor`** — a self-contained area: its own `DeferredSortableList`,
  `ReorderAreaContext` (with this plugin's item chrome) and trailing
  `RestoreButton`, wired to the field's `onChange`.
- **`ReorderItemChrome`** — what an editable `ReorderItemBox` (from `reorder/area`)
  mounts ahead of its content: the hide ×-badge, the empty-item placeholder, and
  the classes it publishes for the box and its content wrapper.
- **`RestoreButton`** (hidden items + registry inserts popover) and
  **`sortableIdsOf`** (an area's sortable ids: a container's members, never itself).

It imports `reorder/area` (the drawing contract), never `reorder/web`. It knows
nothing about config_v2, the live catalog, the `ReorderTree` format, or any node
type: the field renderer pre-renders its nodes via the node-type registry and
maps its data into `entries` + callbacks.
