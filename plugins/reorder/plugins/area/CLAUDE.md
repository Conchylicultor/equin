# area

What a reorder area in the layout EDITOR draws — the Config pane's reorder-tree
field (`fields/reorder-tree/config`) rendering `reorder/editor`'s
`ReorderEditor`. Applying a layout in the app (`reorder`) draws none of it: its
items render bare.

- `ReorderAreaContext` / `ReorderAreaCtxValue` — the area's orientation, its
  hide / remove-node writes, and the `ItemChrome` an editable item mounts.
- `ReorderItemBox` — one item: a `DeferredSortableItem` around a content wrapper,
  dressed by `ItemChrome` (a sibling of the content, never a wrapper).
- The entry types (`ReorderEntry`) and the item-chrome contract.

A leaf so both the field renderer and `reorder/editor` can import it without a
cycle. It imports no drag code (`sortable-list/deferred-item` only).
